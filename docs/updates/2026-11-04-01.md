# 収録範囲と機材・技術を拡充

2026-11-04 · 573 件追加 / 260 件変更 / 0 件整理

衣裳・メイク、楽器・邦楽、電源・通信を追加。音響・照明・映像・舞台機構の用語と説明を拡充し、公式資料で確認した機材・固有機能を収録。9分野・83小分類に整理しました。

## 追加

- **AB方式**（音響）
  二本のマイクを離して置き、主に到達時間差などを使ってステレオ感を得る方式。無指向性マイクの組み合わせなどで用いられる。
  ID: `audio-ab`
- **吸音**（音響）
  音が材料や構造に入射したとき、反射として戻るエネルギーを減らすこと。室内の反射や残響を調整するために用いる。
  ID: `audio-absorption`
- **ADATオプティカル**（音響）
  光ケーブルで複数チャンネルの音声を伝送する方式。オーディオインターフェースや外部マイクプリの入出力拡張に使われる。
  ID: `audio-adat`
- **Axient Digital PSM**（音響）
  Shureのデジタルインイヤーモニターシステム。送信・受信と運用モードを組み合わせて、舞台上の出演者へ音声を届ける。
  ID: `audio-adpsm-equipment`
- **AES3**（音響）
  二チャンネルのデジタル音声を直列伝送する規格。音声にクロックや状態情報などを含め、業務用機器間の接続に使う。
  ID: `audio-aes3`
- **AES50**（音響）
  Ethernetの物理層を利用する高分解能の多チャンネル音声接続規格。舞台用の卓と入出力機器などを結ぶ用途で使われる。
  ID: `audio-aes50`
- **AES67**（音響）
  高性能な音声ストリーミングをIPネットワークで相互運用するための規格。既存の複数方式が共通して扱える条件を定める。
  ID: `audio-aes67-term`
- **エイリアシング**（音響）
  標本化で表現可能な範囲を超えた成分が、別の周波数として現れる現象。AD変換や、非線形なデジタル処理でも問題になる。
  ID: `audio-aliasing`
- **オールパスフィルター**（音響）
  振幅の周波数特性を大きく変えず、位相の関係を変えるフィルター。複数経路の整合やエフェクトの構成などに使われる。
  ID: `audio-allpass`
- **アンビソニックス**（音響）
  音場を方向の基底成分で表現し、再生時にスピーカーやヘッドホン向けへ変換する方式。各チャンネルを特定のスピーカーへ直結しない。
  ID: `audio-ambisonics-term`
- **振幅**（音響）
  波形の変化の大きさ。音圧、電圧、デジタル標本値など、どの量を波として表示しているかで単位が変わる。
  ID: `audio-amplitude`
- **アンテナコンバイナー**（音響）
  複数の送信機のRF出力などをまとめ、共通アンテナへ送る装置。イヤーモニターの多波運用などで使われる。
  ID: `audio-antenna-combiner`
- **アンテナ分配**（音響）
  一組の受信アンテナなどから得た電波を、複数の受信機へ分配する構成。音声信号の分岐とは別の高周波系統。
  ID: `audio-antenna-distribution`
- **ANX4**（音響）
  Shureの多チャンネル無線受信機。Axient DigitalまたはULX-Dの対応モードとチャンネルライセンスを使って、必要数を構成する。
  ID: `audio-anx4-receiver`
- **ASIO**（音響）
  Steinbergが定めた音声入出力の仕組み。Windowsの音声制作環境などで、アプリと対応ドライバーの間の多チャンネル処理に使う。
  ID: `audio-asio-term`
- **AVB**（音響）
  Ethernet上で時間に制約のあるメディアを扱うためのIEEE規格群。時刻同期や帯域確保などを組み合わせて伝送を成立させる。
  ID: `audio-avb-term`
- **Axient Digital Channel Linking**（音響）
  Axient Digital 1.6で紹介された、複数受信機のチャンネル間で主要設定を同期する機能。対応受信機や運用モードの条件がある。
  ID: `audio-axient-channel-link`
- **暗騒音**（音響）
  評価したい音源以外から、その場所で聞こえている騒音。空調、外部交通、客席の動きなどが測定や台詞の聞き取りに影響する。
  ID: `audio-background`
- **ビームステアリング（音響）**（音響）
  複数のスピーカー素子へ異なる処理を与え、主な放射方向や広がりを電気的に制御する技術。筐体の物理角度だけで決める方式と異なる。
  ID: `audio-beamsteering`
- **バイノーラル**（音響）
  左右の耳に届く音の違いを利用して空間感を表す方式。耳付近での収音や、HRTFを使った信号合成などで作る。
  ID: `audio-binaural`
- **ブルムライン方式**（音響）
  二本の双指向性マイクを交差させて用いる一致型のステレオ方式。前後の音も拾うため、室内の響きの影響を受ける。
  ID: `audio-blumlein`
- **バウンス**（音響）
  複数の音声や処理結果を、新しい音声ファイルなどへまとめること。DAWでは最終出力や一部トラックの確定に使われる。
  ID: `audio-bounce`
- **バッファーサイズ**（音響）
  コンピューターが音声をまとめて入出力・処理する単位の大きさ。通常は標本数で表し、処理余裕と遅延の両方に関係する。
  ID: `audio-buffer`
- **バズ**（音響）
  高調波成分を多く伴う、ざらついた持続雑音の呼び方。電源由来の漏れや電気的な干渉など、原因は一つに限らない。
  ID: `audio-buzz`
- **BWF**（音響）
  WAVEを基に、放送制作などに必要なメタデータを追加した音声ファイル形式。音声内容と識別・時刻情報などを一緒に扱う。
  ID: `audio-bwf-term`
- **校正**（音響）
  測定器の指示と、基準による値の関係を確認・記録すること。必要な調整作業や、測定結果の補正とは厳密には区別される。
  ID: `audio-calibration-term`
- **音響校正器**（音響）
  マイクへ既知の音圧を与え、測定系の感度確認や調整に使う装置。マイク径、アダプター、校正条件の適合が必要になる。
  ID: `audio-calibrator`
- **カーディオイドサブ**（音響）
  複数の放射面やユニットの配置・処理により、低域の前後などへの放射量を非対称にする構成。後方音を減らす設計などに使う。
  ID: `audio-cardioid-sub`
- **チャンネルベース音響**（音響）
  左右や中央、サラウンドなど特定の出力チャンネルへ音を割り当てて制作・再生する方法。音源単位の位置情報とは管理方法が違う。
  ID: `audio-channel-audio`
- **コーラス（音響処理）**（音響）
  わずかに変化する遅延や音高差を持つ音を重ね、複数の演奏が重なるような広がりを作るエフェクト。合唱そのものとは区別する。
  ID: `audio-chorus`
- **クリックトラック**（音響）
  テンポや拍の基準を演奏者へ伝えるための音声トラック。客席向けの音源と分け、舞台側のモニターへ送る構成がある。
  ID: `audio-click-track`
- **CMRR**（音響）
  差動入力で、両方の信号線へ共通に入った成分をどの程度抑えられるかを示す比。バランス系統の雑音耐性に関係する。
  ID: `audio-cmrr`
- **同軸ケーブル（RF）**（音響）
  中心導体と周囲の導体を同軸に配置した伝送線。無線音響ではアンテナと機器間の高周波信号を運ぶ用途などで使われる。
  ID: `audio-coax`
- **コヒーレンス**（音響）
  伝達関数測定で、参照信号と測定信号の関係の安定性を示す指標。雑音、時間変動、同期の不一致などに影響される。
  ID: `audio-coherence-term`
- **コンボリューションリバーブ**（音響）
  空間や機器のインパルス応答を音源へ畳み込み、その特性を加えるリバーブ。実在空間の応答を素材として使える。
  ID: `audio-convolution-reverb`
- **周波数コーディネーション**（音響）
  同時に使う無線機器の周波数を、外来波や相互変調、機器の対応範囲などを考慮して組み合わせる作業。単なる空き検索とは異なる。
  ID: `audio-coordination`
- **Core Audio**（音響）
  AppleのOSで音声処理や入出力を扱う基盤技術。音声アプリは対応する機器やシステムの経路を通じて音をやり取りする。
  ID: `audio-coreaudio`
- **クレストファクター**（音響）
  波形のピーク値と実効値の比。衝撃的な変化がどの程度大きいかを示し、信号の性質や余裕を考える際に使われる。
  ID: `audio-crest`
- **臨界距離**（音響）
  室内で直接音と残響音のエネルギーが同程度となる距離の目安。音源の指向性や室内の吸音条件などに左右される。
  ID: `audio-critical-distance`
- **クロストーク**（音響）
  本来別の回線やチャンネルの信号が、他の経路へ漏れ込む現象。電気回路や変換器などの分離性能の評価に使う。
  ID: `audio-crosstalk`
- **Dante Connect**（音響）
  Danteネットワークとクラウド制作環境を結ぶためのAudinateのソリューション群。会場の音声を離れた制作処理へ受け渡す構成で使う。
  ID: `audio-dante-connect`
- **Dante Director**（音響）
  複数のDante機器や拠点を、クラウドを使って監視・管理するAudinateのサービス。論理的なグループ、権限、状態の確認などを扱う。
  ID: `audio-dante-director`
- **Danteフロー**（音響）
  Danteで複数の音声チャンネルなどをまとめて運ぶ伝送の単位。チャンネル数とは別に、機器の送受信フロー数の上限がある。
  ID: `audio-dante-flow`
- **Dante冗長伝送**（音響）
  対応機器で同じ音声を独立した二つのネットワークへ送り、一方の経路障害に備えるDanteの仕組み。通常の二口スイッチ接続と異なる。
  ID: `audio-dante-redundancy`
- **DAW**（音響）
  録音、編集、ミックス、処理などを行う音声制作環境。ソフトウェアを指すことが多く、音声ドライバーや外部機器と連携する。
  ID: `audio-daw`
- **dBFS**（音響）
  デジタル音声のフルスケールを基準にした相対レベル。ファイルやデジタル機器のメーターを読む際に用いる。
  ID: `audio-dbfs`
- **dBu**（音響）
  電圧の実効値を約〇・七七五ボルトに対する比で表す単位。業務用音声の基準レベルや入出力の上限などに使われる。
  ID: `audio-dbu`
- **dBV**（音響）
  一ボルト実効値を基準にした電圧レベルの単位。再生機器や測定器の入出力仕様に現れ、dBuとは基準が異なる。
  ID: `audio-dbv`
- **ディケイ**（音響）
  リバーブや音作りで、音が時間とともに小さくなる過程やその長さを示す言葉。どの減衰区間を指すかは処理機器による。
  ID: `audio-decay`
- **ディエッサー**（音響）
  声のサ行などが強く出る瞬間を検出し、目立ち方を抑える処理。高域を常時下げるEQと異なり、時間的な変化へ反応する。
  ID: `audio-deesser`
- **拡散（音響）**（音響）
  反射音を特定の方向へ集中させず、さまざまな方向や時刻へ分布させること。音を吸収して消す吸音とは別の働き。
  ID: `audio-diffusion`
- **直接音**（音響）
  反射面を経由せず、音源から聴取点へ直接届く音。室内では反射音や残響と混ざり、距離により相対的な寄与が変わる。
  ID: `audio-direct-sound`
- **ディザ**（音響）
  量子化の誤差が信号に連動した歪みとして現れにくくなるよう、微小な雑音を加える方法。主にビット深度の変換で用いる。
  ID: `audio-dither-term`
- **DM Editor**（音響）
  DM7とDM5シリーズのオンライン操作とオフライン設定に対応するYamahaのWindows・Mac用アプリ。旧DM7 Editorとの名称の違いにも注意する。
  ID: `audio-dm-editor`
- **DM5シリーズ**（音響）
  Yamahaが二〇二六年九月に発表したデジタルミキサー群。DM5とDM5 Compactがあり、入力処理数や本体アナログ入力などが異なる。
  ID: `audio-dm5-series`
- **DM7 Comp Assist**（音響）
  DM7 Firmware V2.0で追加された、入力信号のレベルを基にコンプレッサー設定を提案する支援機能。一般的なコンプ全体の名称ではない。
  ID: `audio-dm7-comp-assist`
- **DM7**（音響）
  Yamahaのデジタルミキサー。DM7とDM7 Compactで入力処理数や本体入出力などが異なり、シリーズ内でも仕様を区別して扱う。
  ID: `audio-dm7-console`
- **DM7 Split Mode**（音響）
  DM7シリーズの入力チャンネル、シーン、ミックスバスなどを二つに分け、一台を別々のミキサーのように運用する機能。
  ID: `audio-dm7-split-mode`
- **ドライ・ウェット**（音響）
  未処理音をドライ、処理音をウェットと呼び、その混ぜ方を示す。リバーブや並列処理などで使われる。
  ID: `audio-drywet`
- **DS100M**（音響）
  d&b Soundscapeで使う、MilanとMADIに対応した音声マトリクス・処理エンジン。オブジェクト位置と出力系統の計算に使う。
  ID: `audio-ds100m-engine`
- **Dante Virtual Soundcard PRO**（音響）
  コンピューターの有線ネットワークをDanteの音声入出力として使うソフトウェアのPRO版。OSの音声方式を介してDAWなどと接続する。
  ID: `audio-dvs-pro`
- **ダイナミックEQ**（音響）
  検出信号の状態に応じて、特定帯域の増減量などを変えるEQ。常時同じ補正を行う静的なEQとは動作が異なる。
  ID: `audio-dynamic-eq`
- **初期反射**（音響）
  直接音の後に比較的早く到来する反射音。床、壁、天井などの経路により、音色や定位、空間の広がりの感じ方へ影響する。
  ID: `audio-early-reflection`
- **En-Scene**（音響）
  d&b Soundscapeの音源位置を扱う機能。音響オブジェクトの位置に基づき、スピーカーへのレベルや遅延を計算する。
  ID: `audio-en-scene`
- **En-Space**（音響）
  d&b Soundscapeで室内の響きを再現・付加するための機能。音源位置を計算するEn-Sceneとは別の役割を持つ。
  ID: `audio-en-space`
- **エンドファイア**（音響）
  放射方向に沿って複数の音源を並べ、距離と時間差などを使って指向性を作るアレイ構成。サブウーファーの配置などで用いられる。
  ID: `audio-endfire`
- **FFT**（音響）
  時間波形を周波数成分へ分解する計算を効率よく行う方法。音声解析ではスペクトルや伝達特性を求める基礎に使う。
  ID: `audio-fft`
- **FIRフィルター**（音響）
  インパルス応答が有限の長さで終わるデジタルフィルター。係数や遅延の組み合わせで、周波数・位相特性を設計する。
  ID: `audio-fir`
- **FLAC**（音響）
  元の音声データを復元できる可逆圧縮方式。符号化したファイル容量を減らし、復号後は元の標本値へ戻せる。
  ID: `audio-flac`
- **フランジャー**（音響）
  短い遅延音を原音と混ぜ、その時間差を動かして、櫛形の周波数変化が移動するような響きを作る処理。
  ID: `audio-flanger`
- **フラッターエコー**（音響）
  平行で反射の強い面などの間で反射が繰り返され、細かい反復として聞こえる現象。長い残響時間そのものとは区別する。
  ID: `audio-flutter`
- **基音**（音響）
  周期的な音の基本となる周波数成分。倍音はその整数倍の周波数に現れ、楽器や声の音高・音色の説明に使う。
  ID: `audio-fundamental`
- **ゲインリダクション**（音響）
  コンプレッサーやゲートなどが、元の信号に対してどれだけ利得を下げているかを示す量。入力・出力レベルとは別の表示。
  ID: `audio-gain-reduction`
- **グラウンドリフト**（音響）
  音声の接続で基準やシールドのつながり方を変え、接地経路による雑音の影響を抑える機能。機器によって回路構成が異なる。
  ID: `audio-groundlift`
- **ガイドトラック**（音響）
  演奏や上演の進行を補助するための参考音声。曲名、入りのカウント、次の動作などを出演者や担当者へ知らせる用途がある。
  ID: `audio-guide-track`
- **倍音**（音響）
  基音の整数倍の周波数を持つ成分。成分同士の比率や時間変化は、同じ音高でも楽器や声の音色が違う要因となる。
  ID: `audio-harmonics`
- **ヘッドトラッキング**（音響）
  聴取者の頭の向きや動きを検出し、音の方向などの計算へ反映する仕組み。頭を動かしても仮想音源を空間内へ保つ用途がある。
  ID: `audio-headtracking`
- **ヘリカルアンテナ**（音響）
  導体をらせん状に構成したアンテナ。プロ音響では指向性や偏波の特徴を利用して、IEMなどの無線系統で用いられる。
  ID: `audio-helical`
- **ホールドタイム**（音響）
  ゲートやコンプレッサーなどで、ある動作状態を維持する時間を決めるパラメーター。どの段階を保持するかは処理方式による。
  ID: `audio-hold`
- **HRTF**（音響）
  音源から両耳までの経路で、頭や耳介、胴体などが与える方向別の音響特性。バイノーラル合成で方向感を作るために利用する。
  ID: `audio-hrtf-term`
- **ハム**（音響）
  電源周波数などに関係する低い持続雑音。電磁誘導、接地経路、電源回路など、複数の原因で生じる場合がある。
  ID: `audio-hum`
- **IIRフィルター**（音響）
  出力の一部を内部計算へ戻す再帰構造などを持ち、理論上は応答が無限に続くフィルター。少ない計算量で特性を作りやすい。
  ID: `audio-iir`
- **インパルス応答**（音響）
  ごく短い入力に対し、システムの出力が時間とともにどう変化するかを表す応答。音の到達や反射、減衰の分析に使う。
  ID: `audio-impulse`
- **遮音**（音響）
  壁、床、扉などを隔てた音の伝達を抑えること。空気経由の音と構造を伝わる振動では、支配的な経路が異なる。
  ID: `audio-isolation`

  ID: `video-straight-alpha`
- **タリー**（映像・制御）

  ID: `video-tally`

  ID: `video-tessera-frameremap`

  ID: `video-tessera-shuttersync`
- **トーンマッピング**（映像・制御）
  素材の明暗範囲を、表示装置などの表現できる範囲へ写し替える処理。単に全体の明るさを下げることとは異なる。
  ID: `video-tone-map`
- **トランスコード**（映像・制御）
  符号化された映像を別のコーデックや設定へ変換する処理。入れ物だけを変えるリラップとは区別する。
  ID: `video-transcode`
- **EOTF**（映像・制御）

  ID: `video-transfer-eotf`
- **トランジションプレビュー**（映像・制御）
  本番出力を変えずに、次の映像切替や合成の変化をプレビュー側で確認する機能。
  ID: `video-transition-preview`
- **UHD**（映像・制御）
  超高精細テレビの映像体系。一般的な4K UHDの画素構成は3840×2160で、映画向けのDCI 4Kとは区別する。
  ID: `video-uhd`
- **アップ／ダウンコンバーター**（映像・制御）
  SD、HD、UHDなど異なる映像規格の間で解像度などを変換する処理や装置。
  ID: `video-updown`
- **アップストリームキーヤー**（映像・制御）
  通常、M/Eの背景切替と組み合わせて合成を行うキー処理部。最終段のダウンストリーム処理と区別する。
  ID: `video-usk`
- **UVマップ**（映像・制御）
  三次元形状の表面上の位置と、二次元画像の位置を対応させるための座標情報。形状のXYZ座標とは別に持つ。
  ID: `video-uv-map`
- **映像ビット深度**（映像・制御）

  ID: `video-video-bitdepth`
- **ビットレート（映像）**（映像・制御）
  映像データが単位時間にどれだけ流れるかを示す量。圧縮品質、必要な伝送帯域、保存容量に関係する。
  ID: `video-video-bitrate`
- **ホワイトバランス**（映像・制御）
  照明下の白色をどのように画像の白として扱うかを調整するカメラや画像処理の機能。
  ID: `video-whitebalance`
- **YCbCr**（映像・制御）
  映像を明るさに相当する成分と二つの色差成分で表す方法。RGBとは数値の意味が異なる。
  ID: `video-ycbcr`

## 変更

- **AD・DA変換**（音響） — 変更項目: subcategory
  アナログの連続した音声信号とデジタルの数値表現を相互に変換する処理。入力側がAD、出力側がDAに対応する。

- **パワーアンプ**（音響） — 変更項目: subcategory

- **アタックタイム**（音響） — 変更項目: subcategory
  ダイナミクス処理が入力の変化に反応して所定の減衰や開放へ進む速さを決める時間パラメーター。音の立ち上がりに関係する。
  ID: `audio-attack`
- **音響キュー**（音響） — 変更項目: subcategory
  上演中に音の再生・停止・音量変化などを実行する単位、またはその実行の合図。番号ときっかけを対応させて管理する。
  ID: `audio-audio-cue`
- **AUX**（音響） — 変更項目: sources / detail / examples / pitfalls
  メインのミックスとは別の比率で各入力を混ぜて送る補助経路。出演者用モニター、外部エフェクト、録音などに使う。
  ID: `audio-aux`
- **バランス伝送**（音響） — 変更項目: sources / detail / examples / pitfalls
  対になる二本の信号線と受信側の差動処理を利用し、両線へ共通に入る雑音の影響を抑える伝送方式。
  ID: `audio-balanced`
- **BGM**（音響） — 変更項目: subcategory
  背景として流す音楽。開場中の雰囲気づくりや場面の補助などに使い、演奏そのものを主として聴かせる場面とは区別する。
  ID: `audio-bgm`
- **ビット深度**（音響） — 変更項目: subcategory
  デジタル音声の一つの標本を表すビットの数。表現できる細かさや量子化の特性に関係し、サンプルレートとは別の項目。
  ID: `audio-bit-depth`
- **バウンダリーマイク**（音響） — 変更項目: sources / detail / examples / pitfalls
  床や机などの面の近くに振動板を配置して収音するマイク。舞台面、会議卓、楽器などの収音で用いられる。
  ID: `audio-boundary`
- **カーディオイド**（音響） — 変更項目: sources / detail / examples / pitfalls
  前方の音に強く、真後ろの音に対して感度が低い心臓形の指向性。ステージ用のボーカルマイクなどで使われる。
  ID: `audio-cardioid`
- **クリッピング**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  信号が回路やデジタル表現の上限を超え、波形が正常に表せなくなること。歪みの原因となり、途中段でも発生する。
  ID: `audio-clip`
- **コムフィルター**（音響） — 変更項目: subcategory
  同じ音が異なる時間差で重なり、周波数特性に山と谷が繰り返し生じる現象。反射音や複数の収音・再生経路で起こる。
  ID: `audio-comb`
- **コンプレッサー**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  入力レベルの変化に応じて利得を変え、主に大きな音を抑えて強弱の幅を整える処理。音色や立ち上がりにも影響する。
  ID: `audio-compressor`
- **コンデンサーマイク**（音響） — 変更項目: sources / detail / examples / pitfalls
  振動板と電極の間の容量変化を利用して音を電気信号へ変えるマイク。内部回路の動作に電源を必要とする。
  ID: `audio-condenser-mic`
- **クロスフェード**（音響） — 変更項目: subcategory
  一方の音を下げるのと重ねて別の音を上げ、二つの音を移り変わらせること。重ねる時間と音量曲線で聞こえ方が変わる。
  ID: `audio-crossfade`
- **クロスオーバー**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  再生する周波数帯域を分け、各スピーカーやユニットへ送る仕組み。周波数だけでなくフィルターの種類と傾きも関係する。
  ID: `audio-crossover`
- **Dante**（音響） — 変更項目: subcategory / detail / examples / pitfalls
  Audinateが開発するネットワークを使った音声・映像の伝送技術。対応機器間でチャンネルの接続や同期を行う。
  ID: `audio-dante`
- **DCA・VCA**（音響） — 変更項目: sources / detail / examples / pitfalls
  複数チャンネルのレベルを一括操作する制御グループ。音声を一つのバスへ加算するグループバスとは役割が異なる。
  ID: `audio-dca`
- **デシベル**（音響） — 変更項目: subcategory
  基準に対する比を対数で表す単位。音響では音圧や電気信号のレベル、増幅量などに使い、何を基準にした値かが重要になる。
  ID: `audio-decibel`
- **ディレイ**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  音を時間的に遅らせる処理。反復する効果音作りにも、離れたスピーカー同士の到達時間調整にも使われる。

- **ディレイスピーカー**（音響） — 変更項目: subcategory
  主系統から離れた客席などを補うスピーカー。主系統との音の到達関係に合わせて、電気的な遅延を設定する構成が多い。

- **DI**（音響） — 変更項目: sources / detail / examples / pitfalls
  主に楽器などの出力を卓のマイク入力で扱いやすい信号へ変換する機器。インピーダンスや伝送方式の変換などを行う。
  ID: `audio-di`
- **指向性**（音響） — 変更項目: sources / detail / examples / pitfalls
  音の到来方向によってマイクの感度がどのように変わるかを表す特性。周波数によっても変化し、図で示される。
  ID: `audio-directivity`
- **ダッキング**（音響） — 変更項目: subcategory

  ID: `audio-ducking`
- **イコライザー**（音響） — 変更項目: subcategory
  周波数帯域ごとの信号レベルを調整して音色や特性を変える処理。入力の音作りやスピーカー系統の補正などに使う。
  ID: `audio-eq`
- **エキスパンダー**（音響） — 変更項目: subcategory
  入力の大小に応じて強弱差を広げる処理。小さい信号をさらに下げる方式は、ゲートより緩やかな減衰にも使われる。
  ID: `audio-expander`
- **フェード**（音響） — 変更項目: subcategory
  音量などの値を時間をかけて変化させること。徐々に現れるフェードインと、徐々に消えるフェードアウトなどがある。
  ID: `audio-fade`
- **ハウリング**（音響） — 変更項目: subcategory / detail / examples / pitfalls
  スピーカーの音をマイクが拾い、その信号が再び増幅される循環で特定の音が成長する現象。音響帰還ともいう。
  ID: `audio-feedback`
- **FOH**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  音響では客席向けの音を調整する場所や担当を指す。舞台上の演奏者へ返すモニターミックスと区別して使う。
  ID: `audio-foh`
- **周波数**（音響） — 変更項目: subcategory
  周期的な振動が一秒間に繰り返される回数。音では主に高さに関係し、イコライザーで扱う帯域の位置を表す。
  ID: `audio-frequency`
- **フロントフィル**（音響） — 変更項目: subcategory
  メインスピーカーだけでは届きにくい客席前方を補うスピーカー。主系統と音量や音の到達時間を合わせて設計する。

- **ゲイン**（音響） — 変更項目: sources / detail / examples / pitfalls
  信号をどの程度増幅または減衰するかを表す量。卓ではマイク入力の初段増幅を指すことが多く、後段の音量操作と区別する。
  ID: `audio-gain`
- **ノイズゲート**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  入力が指定した条件を下回ると信号を減衰させる処理。音が出ていない区間の雑音やかぶりを目立ちにくくする用途がある。
  ID: `audio-gate`
- **グラフィックEQ**（音響） — 変更項目: subcategory
  あらかじめ決まった複数帯域をそれぞれ増減するイコライザー。スライダー位置が周波数特性の形を視覚的に示す。
  ID: `audio-geq`
- **グループバス**（音響） — 変更項目: sources / detail / examples / pitfalls
  複数の入力音を合成して一つのまとまりとして処理・操作する経路。合成した音をメインなどへ送ることができる。
  ID: `audio-group-bus`
- **ヘッドルーム**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  通常運用する信号レベルから、歪みやクリップが生じる上限までの余裕。急な大きい音を扱う際の重要な指標となる。
  ID: `audio-headroom`
- **ヘッドセットマイク**（音響） — 変更項目: sources / detail / examples / pitfalls
  頭部や耳まわりに装着し、口元近くの位置を保つマイク。話者が動いても口との距離を比較的一定にしやすい。

- **ハイパスフィルター**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  高い側の周波数を通し、設定した境界より低い帯域を減衰させる処理。減衰の傾きと境界周波数が特性を決める。
  ID: `audio-hpf`
- **イヤーモニター**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls
  出演者が耳に装着するイヤホンで必要な音を聞くモニター方式。専用のミックスを有線または無線で届ける。

- **インピーダンス**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls

- **インサート**（音響） — 変更項目: sources / detail / examples / pitfalls
  音声経路の途中から信号を外部または内部の処理へ送り、その戻りを同じ経路へ組み込む接続。直列の処理として扱う。

- **オーディオインターフェース**（音響） — 変更項目: subcategory
  コンピューターと外部の音声機器の間で入出力を行う装置。アナログ変換、デジタル接続、モニター機能などの構成は製品による。

  衣服や身体に取り付けて使う小型マイク。装着位置、衣擦れ、指向性などが音に影響し、無線・有線の両方式がある。

- **ラインアレイ**（音響） — 変更項目: subcategory / sources / detail / examples / pitfalls

  音源から卓までの信号経路が、予定したチャンネルに正しく入り動作するかを確認する工程。音作りや演奏全体の確認とは区別する。

  低い側の周波数を通し、設定した境界より高い帯域を減衰させる処理。サブウーファーの帯域分けなどにも使う。
  ID: `audio-lpf`

  客席へ主な音を届けるスピーカー系統。左右構成、中央構成など会場により異なり、補助スピーカーと組み合わせて使う。

  複数のミックスやバスを組み合わせ、別の出力ミックスを作る仕組み。客席の補助スピーカーや録音用の分配などに使う。

  舞台上の出演者へ必要な音を返すスピーカー。床置きのくさび形が代表的だが、配置や形状にはさまざまな種類がある。

  ID: `stage-scrim`
- **下手**（舞台・劇場） — 変更項目: detail / examples / pitfalls
  客席から舞台へ向かって左側。舞台上で客席を向いた演者からは右側になり、英米の Stage right に対応する。
  ID: `stage-shimote`
- **見切れ**（舞台・劇場） — 変更項目: detail / examples / pitfalls
  本来隠しておきたい袖や舞台裏、機材などが客席から見えてしまうこと。端の席や上階席を含めた視線で確認する。
  ID: `stage-sightline`
- **サイトスペシフィック**（舞台・劇場） — 変更項目: subcategory
  特定の場所の歴史や構造、雰囲気と結び付けて作る上演。通常の劇場以外を用いることが多いが、場所への固有性が要点。
  ID: `stage-sitespecific`
- **バミリ**（舞台・劇場） — 変更項目: detail / examples / pitfalls
  出演者の立ち位置や道具の設置位置を示す目印。床などに記し、場面ごとの位置を再現するために使う。
  ID: `stage-spike`
- **舞台**（舞台・劇場） — 変更項目: subcategory
  演者が演技や演奏を行うための区域。固定の高い床に限らず、平土間や仮設の会場内に設けた演技空間も含む。
  ID: `stage-stage`
- **平土間客席**（舞台・劇場） — 変更項目: subcategory
  バルコニーなどの上階席に対する、主階床側の客席。日本の伝統劇場の「土間」は座席形式や歴史的区分も含む。
  ID: `stage-stalls`
- **スラストステージ**（舞台・劇場） — 変更項目: subcategory
  舞台が客席へ突き出し、通常三方向を観客に囲まれる配置。額縁舞台に比べ、客席と演者の距離を近づけやすい。
  ID: `stage-thrust`
- **トラップドア**（舞台・劇場） — 変更項目: subcategory
  舞台床などに設ける開閉可能な床の開口。演者や物を出入りさせる演出に使われ、昇降する迫りとは機構が異なる。
  ID: `stage-trapdoor`
- **引割幕**（舞台・劇場） — 変更項目: detail / examples / pitfalls
  中央付近から左右へ分かれて開閉する幕。舞台を前後に区切ったり、後方の装置を隠したりするために使う。
  ID: `stage-traveller`
- **トラバースステージ**（舞台・劇場） — 変更項目: subcategory
  細長い演技区域を挟み、向かい合う二方向に客席を置く配置。観客が舞台越しに反対側の観客を見る構造になる。
  ID: `stage-traverse`
- **奈落**（舞台・劇場） — 変更項目: subcategory
  本舞台や花道の床下にある空間。迫りや廻り舞台の機構などが置かれ、劇場によって複数の階層を持つ。
  ID: `stage-understage`
- **上部舞台機構**（舞台・劇場） — 変更項目: subcategory
  舞台上方にある、幕や道具などの吊物を扱う機構の総称。バトンや吊り設備などを含み、床側の機構と区別する。
  ID: `stage-upper-machinery`
- **舞台奥**（舞台・劇場） — 変更項目: detail / examples / pitfalls
  舞台のうち客席から遠い側、またはその方向。上下の高さではなく、客席からの前後関係を示す位置表現。
  ID: `stage-upstage`
- **引枠**（舞台・劇場） — 変更項目: detail / examples / pitfalls
  大道具を載せて移動できる、車輪付きの台や枠。装置を組んだ状態で出し入れし、場面転換に利用する。
  ID: `stage-wagon`
- **間口**（舞台・劇場） — 変更項目: subcategory / detail / examples / pitfalls
  舞台や装置の左右方向の幅。舞台全体の幅、プロセニアムの開口幅、実際に使える幅のどれかを区別して示す。
  ID: `stage-width`
- **舞台袖**（舞台・劇場） — 変更項目: subcategory / detail / examples / pitfalls
  演技区域の左右にあり、客席から隠される空間。出演者の待機や出入り、道具の待機や転換に利用する。
  ID: `stage-wings`
- **アルファチャンネル**（映像・制御） — 変更項目: subcategory
  画像や映像の各画素について、透明・不透明の情報を持つチャンネル。色の情報とは別に、他の映像へ重ねる範囲を示す。
  ID: `video-alpha`
- **アスペクト比**（映像・制御） — 変更項目: subcategory
  映像や画面の横幅と高さの比率。解像度の数値そのものではなく、形の比を示し、画面へ収める方法を決める際に用いる。
  ID: `video-aspect`
- **AUX 出力（映像）**（映像・制御） — 変更項目: subcategory
  本線と別の映像を選択して送れる補助出力。会場モニターや収録用など、目的に応じた出力系統を構成する。
  ID: `video-aux`
- **クロマキー**（映像・制御） — 変更項目: subcategory
  指定した色の領域を手掛かりにして背景を抜き、別の映像と合成する方式。緑や青の背景を用いる表現が代表的。
  ID: `video-chromakey`
- **カット（映像）**（映像・制御） — 変更項目: subcategory
  映像を重ねる移行時間を設けず、ある入力から別の入力へ切り替えること。撮影の停止指示や編集単位の意味もある。
  ID: `video-cut`
- **ディゾルブ**（映像・制御） — 変更項目: subcategory
  前の映像を薄くしながら次の映像を重ね、徐々に切り替えるトランジション。
  ID: `video-dissolve`
- **エッジブレンディング**（映像・制御） — 変更項目: subcategory
  複数台の投影範囲が重なる部分の明るさなどを調整し、一続きの画面に見せる処理。
  ID: `video-edgeb`
- **フレームレート**（映像・制御） — 変更項目: subcategory
  動画の一秒あたりのフレーム数。動きの表現や再生互換性に関わり、解像度とは別に素材と機器の設定を確認する。
  ID: `video-framerate`
- **キーヤー**（映像・制御） — 変更項目: subcategory
  キー信号や色・明るさなどの条件を使い、映像の一部を別の映像へ重ねる合成機能。背景と前景の組み合わせを作る。
  ID: `video-keyer`
- **キー／フィル**（映像・制御） — 変更項目: subcategory
  合成する映像の色などを持つフィル信号と、抜きや重なりの範囲を示すキー信号を組み合わせて扱う方式。
  ID: `video-keyfill`
- **台形補正**（映像・制御） — 変更項目: subcategory
  斜め方向から投影したときに生じる台形の歪みを補正する機能。レンズシフトによる位置調整とは別の処理。
  ID: `video-keystone`
- **レンズシフト**（映像・制御） — 変更項目: subcategory
  レンズの位置を動かして投影画面を上下左右へ移動する光学的な調整機能。対応方向と範囲は機種により異なる。
  ID: `video-lensshift`
- **プロジェクションマッピング**（映像・制御） — 変更項目: subcategory
  立体物や舞台装置の形状・位置に合わせて映像を変形し、投影範囲を割り当てる表現手法。
  ID: `video-mapping`
- **マルチビュー**（映像・制御） — 変更項目: subcategory
  複数の入力やプログラム、プレビューなどを一つの画面に分割表示する監視機能。
  ID: `video-multiview`
- **NDI**（映像・制御） — 変更項目: subcategory
  IP ネットワーク上で映像・音声・メタデータをやり取りする技術群。単独のコーデック名ではなく、形式により帯域や遅延が異なる。
  ID: `video-ndi`
- **プレイヘッド**（映像・制御） — 変更項目: subcategory
  現在の再生位置や次に実行するキューの位置を示すもの。タイムライン方式とキュー方式で表示の意味が異なる。
  ID: `video-playhead`
- **ポストウェイト**（映像・制御） — 変更項目: subcategory
  キュー本体の開始後から自動継続までの待ち時間を示す設定。QLab ではキュー本体の終了から数える時間とは限らない。
  ID: `video-postwait`
- **プレビュー**（映像・制御） — 変更項目: subcategory
  本番出力へ切り替える前に確認する映像や出力。プログラムとは別に、次に使用する素材を点検できる。
  ID: `video-preview`
- **プリウェイト**（映像・制御） — 変更項目: subcategory
  キューを起動してから、その内容の実行が始まるまでに設ける待ち時間。主にキュー再生ソフトの用語。
  ID: `video-prewait`
- **プログラム**（映像・制御） — 変更項目: subcategory
  スイッチャーで実際に送出中の映像、またはその出力系統。公演の演目表を意味するプログラムとは文脈が異なる。
  ID: `video-program`
- **プロジェクター**（映像・制御） — 変更項目: subcategory
  光学系を使って映像をスクリーンや舞台面へ投影する機器。設置条件、明るさ、レンズの選定が画面に影響する。
  ID: `video-projector`
- **解像度**（映像・制御） — 変更項目: subcategory
  デジタル映像や画面を構成する画素の数。横と縦の画素数で表すことが多く、画面の縦横比やフレームレートとは別の情報。
  ID: `video-resolution`
- **メディアサーバー**（映像・制御） — 変更項目: subcategory
  複数の映像素材の再生・合成・出力を管理するシステム。舞台映像ではキューや外部制御と連携させることがある。
  ID: `video-server`
- **ステージ（映像）**（映像・制御） — 変更項目: subcategory
  QLab 5 で映像キューを配置する仮想的な画面。実際の舞台や、旧版のサーフェスという名称と区別して用いる。
  ID: `video-stage`
- **サーフェス**（映像・制御） — 変更項目: subcategory
  映像を配置・出力する面を表す語。実際の投影面を指す場合と、ソフトウェア内部の仮想面を指す場合がある。
  ID: `video-surface`
- **映像スイッチャー**（映像・制御） — 変更項目: subcategory
  複数の映像入力から出力する映像を選び、切替や合成を行う機器。音響のミキサーとは扱う主信号が異なる。
  ID: `video-switcher`
- **投写比**（映像・制御） — 変更項目: subcategory
  投写距離を投写画面の幅で割った比率。必要な画面幅と設置距離に適するレンズを考える際に使う。
  ID: `video-throw`
