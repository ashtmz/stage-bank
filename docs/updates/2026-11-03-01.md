# 初期収録

2026-11-03 · 462 件追加 / 0 件変更 / 0 件整理

舞台・音響・照明を中心とする462語の初期版。

## 追加

- **AD・DA変換**（音響）
  アナログの連続した音声信号とデジタルの数値表現を相互に変換する処理。入力側がAD、出力側がDAに対応する。
  ID: `audio-ad-da`
- **AFL**（音響）
  フェーダー後の信号を操作側のモニターで聞く機能。出力バスなどの調整後の状態を確認する用途に使われる。
  ID: `audio-afl`
- **パワーアンプ**（音響）
  音声信号をスピーカーユニットを駆動できる電力に増幅する装置。外部機器としてもスピーカー内蔵としても使われる。
  ID: `audio-amp`
- **アタックタイム**（音響）
  ダイナミクス処理が入力の変化に反応して所定の減衰や開放へ進む速さを決める時間パラメーター。音の立ち上がりに関係する。
  ID: `audio-attack`
- **音響キュー**（音響）
  上演中に音の再生・停止・音量変化などを実行する単位、またはその実行の合図。番号ときっかけを対応させて管理する。
  ID: `audio-audio-cue`
- **AUX**（音響）
  メインのミックスとは別の比率で各入力を混ぜて送る補助経路。出演者用モニター、外部エフェクト、録音などに使う。
  ID: `audio-aux`
- **バランス伝送**（音響）
  対になる二本の信号線と受信側の差動処理を利用し、両線へ共通に入る雑音の影響を抑える伝送方式。
  ID: `audio-balanced`
- **BGM**（音響）
  背景として流す音楽。開場中の雰囲気づくりや場面の補助などに使い、演奏そのものを主として聴かせる場面とは区別する。
  ID: `audio-bgm`
- **ビット深度**（音響）
  デジタル音声の一つの標本を表すビットの数。表現できる細かさや量子化の特性に関係し、サンプルレートとは別の項目。
  ID: `audio-bit-depth`
- **かぶり**（音響）
  狙った音源以外の楽器音、周囲の音、スピーカー音などがマイクへ入ること。分離の程度やミックスの質感に影響する。
  ID: `audio-bleed`
- **ボディーパック**（音響）
  衣服や身体に取り付ける小型の送信機または受信機。装着マイク、楽器、イヤーモニターなど、役割により構成が異なる。
  ID: `audio-bodypack`
- **バウンダリーマイク**（音響）
  床や机などの面の近くに振動板を配置して収音するマイク。舞台面、会議卓、楽器などの収音で用いられる。
  ID: `audio-boundary`
- **バス**（音響）
  複数の信号を集めて合成し、次の処理や出力へ渡す経路。メイン、AUX、グループ、マトリクスなど用途で分かれる。
  ID: `audio-bus`
- **カーディオイド**（音響）
  前方の音に強く、真後ろの音に対して感度が低い心臓形の指向性。ステージ用のボーカルマイクなどで使われる。
  ID: `audio-cardioid`
- **入力チャンネル**（音響）
  一つの入力音を受けて処理・分配するミキサー内部の経路。物理的な入力端子と内部チャンネルの対応は変更できる場合がある。
  ID: `audio-channel`
- **クリッピング**（音響）
  信号が回路やデジタル表現の上限を超え、波形が正常に表せなくなること。歪みの原因となり、途中段でも発生する。
  ID: `audio-clip`
- **コムフィルター**（音響）
  同じ音が異なる時間差で重なり、周波数特性に山と谷が繰り返し生じる現象。反射音や複数の収音・再生経路で起こる。
  ID: `audio-comb`
- **コンプレッサー**（音響）
  入力レベルの変化に応じて利得を変え、主に大きな音を抑えて強弱の幅を整える処理。音色や立ち上がりにも影響する。
  ID: `audio-compressor`
- **コンデンサーマイク**（音響）
  振動板と電極の間の容量変化を利用して音を電気信号へ変えるマイク。内部回路の動作に電源を必要とする。
  ID: `audio-condenser-mic`
- **クロスフェード**（音響）
  一方の音を下げるのと重ねて別の音を上げ、二つの音を移り変わらせること。重ねる時間と音量曲線で聞こえ方が変わる。
  ID: `audio-crossfade`
- **クロスオーバー**（音響）
  再生する周波数帯域を分け、各スピーカーやユニットへ送る仕組み。周波数だけでなくフィルターの種類と傾きも関係する。
  ID: `audio-crossover`
- **Dante**（音響）
  Audinateが開発するネットワークを使った音声・映像の伝送技術。対応機器間でチャンネルの接続や同期を行う。
  ID: `audio-dante`
- **DCA・VCA**（音響）
  複数チャンネルのレベルを一括操作する制御グループ。音声を一つのバスへ加算するグループバスとは役割が異なる。
  ID: `audio-dca`
- **デシベル**（音響）
  基準に対する比を対数で表す単位。音響では音圧や電気信号のレベル、増幅量などに使い、何を基準にした値かが重要になる。
  ID: `audio-decibel`
- **ディレイ**（音響）
  音を時間的に遅らせる処理。反復する効果音作りにも、離れたスピーカー同士の到達時間調整にも使われる。
  ID: `audio-delay`
- **ディレイスピーカー**（音響）
  主系統から離れた客席などを補うスピーカー。主系統との音の到達関係に合わせて、電気的な遅延を設定する構成が多い。
  ID: `audio-delay-speaker`
- **DI**（音響）
  主に楽器などの出力を卓のマイク入力で扱いやすい信号へ変換する機器。インピーダンスや伝送方式の変換などを行う。
  ID: `audio-di`
- **ダイレクトアウト**（音響）
  入力チャンネルの音を個別に外へ取り出す出力。マルチトラック録音や別システムへの分配などに使われる。
  ID: `audio-direct-out`
- **指向性**（音響）
  音の到来方向によってマイクの感度がどのように変わるかを表す特性。周波数によっても変化し、図で示される。
  ID: `audio-directivity`
- **ダイバーシティー**（音響）
  複数の受信経路などを利用して、場所や反射による電波の弱まりの影響を減らす方式。切替や合成などの実装がある。
  ID: `audio-diversity`
- **ドロップアウト**（音響）
  信号が連続して得られず、一時的に音が途切れる現象。無線、デジタル伝送、再生処理など、発生原因は系統により異なる。
  ID: `audio-dropout`
- **ダッキング**（音響）
  別の音声や制御信号が入ったときに、対象の音量を自動的に下げる処理。案内の間だけBGMを抑える用途などに使う。
  ID: `audio-ducking`
- **ダイナミックマイク**（音響）
  音で振動するコイルと磁界を利用して電気信号を作るマイク。ボーカルや楽器の収音に使われ、指向性とは別の分類。
  ID: `audio-dynamic-mic`
- **イコライザー**（音響）
  周波数帯域ごとの信号レベルを調整して音色や特性を変える処理。入力の音作りやスピーカー系統の補正などに使う。
  ID: `audio-eq`
- **エキスパンダー**（音響）
  入力の大小に応じて強弱差を広げる処理。小さい信号をさらに下げる方式は、ゲートより緩やかな減衰にも使われる。
  ID: `audio-expander`
- **フェード**（音響）
  音量などの値を時間をかけて変化させること。徐々に現れるフェードインと、徐々に消えるフェードアウトなどがある。
  ID: `audio-fade`
- **フェーダー**（音響）
  上下または左右に動かして信号レベルを調整する操作子。入力、バス、DCAなど、割り当てられた対象により働きが異なる。
  ID: `audio-fader`
- **ハウリング**（音響）
  スピーカーの音をマイクが拾い、その信号が再び増幅される循環で特定の音が成長する現象。音響帰還ともいう。
  ID: `audio-feedback`
- **双指向性**（音響）
  前方と後方に感度があり、左右方向の感度が低い指向性。上から見た感度の形が八の字に似るためそう呼ばれる。
  ID: `audio-figure-eight`
- **FOH**（音響）
  音響では客席向けの音を調整する場所や担当を指す。舞台上の演奏者へ返すモニターミックスと区別して使う。
  ID: `audio-foh`
- **フットスイッチ**（音響）
  足で踏んで機器へ操作信号を送るスイッチ。再生・停止や機能切替など、割り当てた操作を手を使わずに行うために用いる。
  ID: `audio-footswitch`
- **周波数**（音響）
  周期的な振動が一秒間に繰り返される回数。音では主に高さに関係し、イコライザーで扱う帯域の位置を表す。
  ID: `audio-frequency`
- **フロントフィル**（音響）
  メインスピーカーだけでは届きにくい客席前方を補うスピーカー。主系統と音量や音の到達時間を合わせて設計する。
  ID: `audio-frontfill`
- **ゲイン**（音響）
  信号をどの程度増幅または減衰するかを表す量。卓ではマイク入力の初段増幅を指すことが多く、後段の音量操作と区別する。
  ID: `audio-gain`
- **ノイズゲート**（音響）
  入力が指定した条件を下回ると信号を減衰させる処理。音が出ていない区間の雑音やかぶりを目立ちにくくする用途がある。
  ID: `audio-gate`
- **グラフィックEQ**（音響）
  あらかじめ決まった複数帯域をそれぞれ増減するイコライザー。スライダー位置が周波数特性の形を視覚的に示す。
  ID: `audio-geq`
- **グループバス**（音響）
  複数の入力音を合成して一つのまとまりとして処理・操作する経路。合成した音をメインなどへ送ることができる。
  ID: `audio-group-bus`
- **ヘッドルーム**（音響）
  通常運用する信号レベルから、歪みやクリップが生じる上限までの余裕。急な大きい音を扱う際の重要な指標となる。
  ID: `audio-headroom`
- **ヘッドセットマイク**（音響）
  頭部や耳まわりに装着し、口元近くの位置を保つマイク。話者が動いても口との距離を比較的一定にしやすい。
  ID: `audio-headset`
- **ハイパスフィルター**（音響）
  高い側の周波数を通し、設定した境界より低い帯域を減衰させる処理。減衰の傾きと境界周波数が特性を決める。
  ID: `audio-hpf`
- **ハイパーカーディオイド**（音響）
  前方の収音範囲をさらに絞り、後方にも一定の感度を持つ指向性。正面以外への感度の落ち方がカーディオイドと異なる。
  ID: `audio-hypercardioid`
- **イヤーモニター**（音響）
  出演者が耳に装着するイヤホンで必要な音を聞くモニター方式。専用のミックスを有線または無線で届ける。
  ID: `audio-iem`
- **インピーダンス**（音響）
  交流信号の流れにくさを表す量で、単位はオーム。音響機器では出力側と入力側の関係が接続条件に影響する。
  ID: `audio-impedance`
- **インサート**（音響）
  音声経路の途中から信号を外部または内部の処理へ送り、その戻りを同じ経路へ組み込む接続。直列の処理として扱う。
  ID: `audio-insert`
- **明瞭度**（音響）
  言葉をどれだけ聞き取りやすいかを表す考え方。音量だけでなく、残響、雑音、周波数特性などの影響を受ける。
  ID: `audio-intelligibility`
- **インカム**（音響）
  舞台進行や技術スタッフ間の連絡に使う通話システム。有線・無線や複数の回線構成があり、公演用の音声出力とは区別する。
  ID: `audio-intercom`
- **オーディオインターフェース**（音響）
  コンピューターと外部の音声機器の間で入出力を行う装置。アナログ変換、デジタル接続、モニター機能などの構成は製品による。
  ID: `audio-interface`
- **相互変調**（音響）
  複数の周波数成分が非線形な回路などで混ざり、新しい周波数成分を生む現象。無線機器の同時使用で干渉要因になる。
  ID: `audio-intermod`
- **レイテンシー**（音響）
  信号が入力されてから出力されるまでに生じる時間の遅れ。変換、処理、バッファー、ネットワークなど複数段の遅れが加わる。
  ID: `audio-latency`
- **ラベリアマイク**（音響）
  衣服や身体に取り付けて使う小型マイク。装着位置、衣擦れ、指向性などが音に影響し、無線・有線の両方式がある。
  ID: `audio-lavalier`
- **リミッター**（音響）
  大きい入力に対して強い圧縮をかけ、出力レベルの上昇を抑える処理。信号管理や機器側の制御などで用いられる。
  ID: `audio-limiter`
- **ラインアレイ**（音響）
  複数のスピーカーユニットや筐体を列状に配置して、相互の干渉を含めた指向性を設計するスピーカー構成。
  ID: `audio-line-array`
- **ラインレベル**（音響）
  ミキサーや再生機器などの間で扱う音声信号のレベル区分。一般にマイクの微弱な出力より大きく、機器ごとに基準がある。
  ID: `audio-line-level`
- **ラインチェック**（音響）
  音源から卓までの信号経路が、予定したチャンネルに正しく入り動作するかを確認する工程。音作りや演奏全体の確認とは区別する。
  ID: `audio-linecheck`
- **ローパスフィルター**（音響）
  低い側の周波数を通し、設定した境界より高い帯域を減衰させる処理。サブウーファーの帯域分けなどにも使う。
  ID: `audio-lpf`
- **メインスピーカー**（音響）
  客席へ主な音を届けるスピーカー系統。左右構成、中央構成など会場により異なり、補助スピーカーと組み合わせて使う。
  ID: `audio-main`
- **マトリクス**（音響）
  複数のミックスやバスを組み合わせ、別の出力ミックスを作る仕組み。客席の補助スピーカーや録音用の分配などに使う。
  ID: `audio-matrix`
- **マイクレベル**（音響）
  マイクが出す比較的微弱な音声信号のレベル区分。マイクの感度や音源の大きさで変わり、通常は入力初段で増幅して扱う。
  ID: `audio-mic-level`
- **ミキサー**（音響）
  複数の入力音を受け、音量や音質、定位、送り先を調整して出力へまとめる装置。アナログ型とデジタル型などがある。
  ID: `audio-mixer`
- **モニタースピーカー**（音響）
  舞台上の出演者へ必要な音を返すスピーカー。床置きのくさび形が代表的だが、配置や形状にはさまざまな種類がある。
  ID: `audio-monitor`
- **マルチキャスト**（音響）
  受信を希望する複数の相手へ、一つの送信ストリームをネットワーク内で分配する方式。同じ音の多地点への配信などに使う。
  ID: `audio-multicast`
- **マルチケーブル**（音響）
  複数の音声回線を一本のケーブルにまとめたもの。舞台と卓の間などで多数の入出力をまとめて引き回すために使う。
  ID: `audio-multicore`
- **マルチパス**（音響）
  直接届く電波と、壁などで反射した電波が異なる経路を通って受信点へ届くこと。強め合いや打ち消しで受信状態が変わる。
  ID: `audio-multipath`
- **マルチトラック録音**（音響）
  複数の音声を別々のトラックに記録すること。客席向けにまとめた音とは別に、各入力を後から調整できる形で残せる。
  ID: `audio-multitrack`
- **ミュート**（音響）
  指定した信号の通過を止める機能。どの出力や送り先に作用するかは、卓の構成と信号の取り出し位置によって異なる。
  ID: `audio-mute`
- **ミュートグループ**（音響）
  複数の入力や出力を一つの操作でまとめて消音するためのグループ。レベルの一括調整を行うDCAとは別の機能。
  ID: `audio-mute-group`
- **ノッチフィルター**（音響）
  狭い周波数帯域を深く減衰させるフィルター。特定の共振や不要成分への処理に使われ、広い帯域の音量調整とは区別する。
  ID: `audio-notch`
- **無指向性**（音響）
  理想的には全方向の音に等しく感度を持つ指向性。音源だけでなく周囲の音も収音し、装着型マイクなどにも使われる。
  ID: `audio-omni`
- **PA**（音響）
  声や音楽を多数の人に届けるための拡声設備や、その運用を指す。舞台ではマイクから客席スピーカーまでの系統を含む。
  ID: `audio-pa`
- **パン**（音響）
  モノラル入力を左右などの出力へどの比率で配るかを決める操作。ステレオ入力のバランス調整とは扱いが異なる。
  ID: `audio-pan`
- **パッシブスピーカー**（音響）
  駆動用パワーアンプを内蔵せず、外部アンプからスピーカー用の信号を受けるスピーカー。対応するアンプや配線を要する。
  ID: `audio-passive`
- **パッチ**（音響）
  機器の端子と信号経路を接続・割り当てすること。ケーブルによる物理接続と、卓内部の設定の両方に用いる。
  ID: `audio-patch`
- **パラメトリックEQ**（音響）
  中心周波数、増減量、帯域幅などを設定して特定帯域を調整するイコライザー。設定できる項目は機種により異なる。
  ID: `audio-peq`
- **PFL**（音響）
  チャンネルフェーダーより前の信号を操作側のモニターで聞く機能。客席へ出すバランスとは独立に入力確認などを行う。
  ID: `audio-pfl`
- **ファンタム電源**（音響）
  マイク用のバランス音声ケーブルを通じて、対応するマイクや機器へ直流電源を供給する方式。音声信号と同じ線を使う。
  ID: `audio-phantom`
- **位相**（音響）
  周期的な波の進み具合、または複数の波の時間的な関係。似た音を重ねると、周波数ごとに強め合いや打ち消しが生じる。
  ID: `audio-phase`
- **極性**（音響）
  信号の正負の向き。極性反転は波形の正負を入れ替える操作であり、信号を時間方向に移動することではない。
  ID: `audio-polarity`
- **ポップノイズ**（音響）
  発話時の強い息がマイクの振動板に当たるなどして生じる低い衝撃的な雑音。言葉の音そのものと区別して扱う。
  ID: `audio-pop`
- **ポストフェーダー**（音響）
  対象のフェーダーより後で信号を取り出す位置を示す言葉。元のチャンネルのフェーダー操作に送りのレベルが追従する。
  ID: `audio-post-fader`
- **パワードスピーカー**（音響）
  駆動用パワーアンプを内蔵したスピーカー。通常は外部から音声信号と電源を受け、内部アンプでユニットを駆動する。
  ID: `audio-powered`
- **プリフェーダー**（音響）
  対象のフェーダーより前で信号を取り出す位置を示す言葉。通常、そのフェーダー操作に追従しない送りとして使われる。
  ID: `audio-pre-fader`
- **近接効果**（音響）
  指向性マイクの一部で、音源を近づけるほど低域が強まる現象。マイクの方式や距離により程度が異なる。
  ID: `audio-proximity`
- **Q**（音響）
  フィルターやEQの鋭さを示す値。ピーキングEQでは一般に値が大きいほど、中心周波数の周りの影響帯域が狭くなる。
  ID: `audio-q`
- **ダイナミックレンジ**（音響）
  音や装置が扱う最小側と最大側のレベルの幅。機器ではノイズと最大無歪出力の関係、音源では強弱の幅を表す。
  ID: `audio-range`
- **リコールセーフ**（音響）
  シーンなどの設定呼び出しで、特定のチャンネルや項目が上書きされないようにする機能。保護範囲は機種ごとに異なる。
  ID: `audio-recall-safe`
- **リリースタイム**（音響）
  入力の状態が変わった後、ダイナミクス処理が減衰量などを戻していく速さを決める時間パラメーター。余韻の出方に関係する。
  ID: `audio-release`
- **リバーブ**（音響）
  反射が重なって減衰する残響の響きを付加・再現する処理。実際の部屋の残響とは分けて、ミックス内で調整できる。
  ID: `audio-reverb`
- **RF**（音響）
  無線で信号を運ぶ高周波、またはその回路や受信状態を示す表記。受信機では音声側を示すAFと区別して使う。
  ID: `audio-rf`
- **リボンマイク**（音響）
  薄い帯状の振動体を磁界の中で動かし、音を電気信号へ変換するマイク。構造や電源の要否は製品により異なる。
  ID: `audio-ribbon-mic`
- **残響時間**（音響）
  音源停止後の残響が一定量減衰する速さを時間で表す指標。RT60は六十デシベルの減衰に相当する時間を指す。
  ID: `audio-rt60`
- **サンプリング周波数**（音響）
  デジタル音声で一秒間に扱う標本の数。単位はHzで、音声の周波数範囲や接続機器間の同期条件に関係する。
  ID: `audio-sample-rate`
- **シーン**（音響）
  デジタル卓などの設定状態を保存し、必要な時点で呼び出す単位。保存対象と呼び出し対象は機種や設定により異なる。
  ID: `audio-scene`
- **SE**（音響）
  効果音を指す略称。場面に必要な環境音や動作音、演出的な音などを指し、短い音だけに限定されるものではない。
  ID: `audio-se`
- **センド・リターン**（音響）
  処理したい音を別経路へ送り、処理後の音を卓へ戻す構成。リバーブなどでは原音と戻り音を混ぜる並列経路として使う。
  ID: `audio-send-return`
- **ショットガンマイク**（音響）
  干渉管などを用いて側方からの音を抑え、前方に鋭い指向性を持たせたマイク。映像収録や舞台収音などに使う。
  ID: `audio-shotgun`
- **サイドチェーン**（音響）
  コンプレッサーやゲートの動作判断に使う検出信号の経路。処理される本体の音とは別の信号を利用できる場合がある。
  ID: `audio-sidechain`
- **サウンドチェック**（音響）
  出演者の声や演奏を実際に出して、客席向け・舞台向けの音のバランスや聞こえ方を確認する工程。回線の確認だけとは区別する。
  ID: `audio-soundcheck`
- **スピーカーケーブル**（音響）
  パワーアンプからパッシブスピーカーへ電力を含む音声を送る専用ケーブル。マイク・ライン用と用途や構造が異なる。
  ID: `audio-speaker-cable`
- **speakON**（音響）
  Neutrikによるスピーカー接続用のロック式コネクター。主にパワーアンプとパッシブスピーカーを結ぶ電力を伴う音声に使う。
  ID: `audio-speakon`
- **音圧レベル**（音響）
  空気の圧力変動の大きさを基準値に対する対数で表した量。測定値には周波数補正や時間特性などの条件が伴う。
  ID: `audio-spl`
- **スプリッター**（音響）
  一つの入力信号を複数の卓やシステムへ分配する装置。FOH、モニター、収録などで同じ音源を共有するために使う。
  ID: `audio-splitter`
- **スケルチ**（音響）
  必要な電波を受信できないときなどに、受信機の音声出力を抑える機能。不要な雑音が出るのを防ぐために用いられる。
  ID: `audio-squelch`
- **SR**（音響）
  生音を電気的に補い、会場全体で適切に聞こえるようにすること。PAと重なるが、音を補強する役割に着目した呼び方。
  ID: `audio-sr`
- **ステージボックス**（音響）
  舞台側でマイクなどを接続する入出力の箱。アナログの接続箱と、変換回路や遠隔制御を備えたデジタル型がある。
  ID: `audio-stagebox`
- **ステレオリンク**（音響）
  二つのチャンネルの設定や操作を連動させ、左右一組として扱う機能。どのパラメーターが連動するかは機種により異なる。
  ID: `audio-stereo-link`
- **サブスクリプション**（音響）
  Danteなどで、受信チャンネルがどの送信チャンネルを受け取るかを指定する接続関係。物理ケーブルとは別の論理的な経路。
  ID: `audio-subscription`
- **サブウーファー**（音響）
  低い周波数帯域の再生を主に担当するスピーカー。メイン系統と帯域を分担し、設置や時間・極性の関係が再生に影響する。
  ID: `audio-subwoofer`
- **スーパーカーディオイド**（音響）
  カーディオイドより前方の収音範囲が狭い指向性。側後方に感度の低い方向がある一方、真後ろにも収音する領域がある。
  ID: `audio-supercardioid`
- **トークバック**（音響）
  音響担当から出演者や舞台スタッフへ連絡する音声経路。客席向けのミックスと分けて指定の送り先へ送ることが多い。
  ID: `audio-talkback`
- **スレッショルド**（音響）
  コンプレッサーやゲートなどで、レベルに応じた処理が変化する基準値。値の単位や基準は処理機器ごとに異なる。
  ID: `audio-threshold`
- **ポン出し**（音響）
  あらかじめ用意した音素材を、ボタンやパッドなどの操作できっかけに合わせて再生すること。機材の種類に限定されない。
  ID: `audio-triggerplay`
- **トリム**（音響）
  入力レベルを補正する調整機能。デジタル卓ではアナログのヘッドアンプ後に置かれるデジタル側の補正を指すことがある。
  ID: `audio-trim`
- **TRS端子**（音響）
  チップ・リング・スリーブの三接点を持つフォーン端子。バランスのモノラル音声、ステレオ音声、インサートなどに使う。
  ID: `audio-trs`
- **TS端子**（音響）
  チップとスリーブの二接点を持つフォーン端子。楽器などのアンバランス信号や、一部のスピーカー接続に使われる。
  ID: `audio-ts`
- **アンバランス伝送**（音響）
  基準となる線に対して一本の信号線の電圧を伝える方式。楽器や民生音声で使われ、外来雑音の影響を受けやすい場合がある。
  ID: `audio-unbalanced`
- **ユニキャスト**（音響）
  一つの送信先へデータを送る通信方式。同じ音を別の相手へも送る場合、送信側から別のデータの流れが必要となる。
  ID: `audio-unicast`
- **ワイヤレスマイク**（音響）
  マイクの音声を送信機から受信機へ電波で伝える方式。ハンドヘルド型や、小型マイクをつなぐボディーパック型がある。
  ID: `audio-wireless-mic`
- **ワードクロック**（音響）
  デジタル音声機器の標本処理のタイミングをそろえる基準。専用線やデジタル音声・ネットワーク内の同期情報で共有する。
  ID: `audio-wordclock`
- **XLR端子**（音響）
  音響で広く使うロック付きコネクターの系統。三極はバランス音声でよく使うが、極数や用途の異なるものもある。
  ID: `audio-xlr`
- **DMXアドレス**（照明）
  DMXユニバース内で機器が制御データを読み始める位置。灯体のモードに応じて複数の連続した値を使う。
  ID: `lighting-address`
- **Art-Net**（照明）
  DMXやRDMのデータなどをEthernetネットワーク上で扱う照明制御プロトコル。対応機器間でユニバース等を設定する。
  ID: `lighting-artnet`
- **バックライト**（照明）
  出演者や対象物の後方から客席側へ向けて当てる光。輪郭を出し、背景との分離や奥行きに役立つ。
  ID: `lighting-backlight`
- **バンドア**（照明）
  灯体の前面に取り付け、光の広がりや漏れを調整する可動式の羽根。内蔵シャッターとは位置と効果が異なる。
  ID: `lighting-barndoor`
- **ビーム角**（照明）
  中心付近の光の広がりを角度で示したもの。測光上の定義を持つため、器具の公称角やフィールド角と区別する。
  ID: `lighting-beamangle`
- **ビーム型ムービング**（照明）
  細く密度のある光線を作る用途に重点を置くムービングライト。空中の光線を演出に使うことが多い。
  ID: `lighting-beamfixture`
- **暗転**（照明）
  舞台の明かりを落として暗い状態にする演出や、その状態。即時か時間をかけるかはキューで区別する。
  ID: `lighting-blackout`
- **ブラックラップ**（照明）
  光を遮ったり形を整えたりするための黒い金属箔状素材。灯体周辺の漏れ光処理などで使う。
  ID: `lighting-blackwrap`
- **ブラインド**（照明）
  舞台へ出力している状態を直接変えずに、記録済みのキューなどを編集する操作領域やモード。
  ID: `lighting-blind`
- **ブロック**（照明）
  トラッキングする値を特定のキューなどで区切り、前の変更が流れ込むことを抑える指示。
  ID: `lighting-block`
- **ブーム**（照明）
  複数の灯体を高さを変えて取り付けるための縦方向の支持設備。舞台袖のサイドライトなどに使う。
  ID: `lighting-boom`
- **色温度**（照明）
  白色光の色味を温度の尺度で表す値。通常ケルビンを使い、光源の実際の表面温度と同じとは限らない。
  ID: `lighting-cct`
- **シーリング**（照明）
  舞台照明では客席の天井付近に設ける照射位置。舞台前方から顔や舞台面を照らす灯体を置く。
  ID: `lighting-ceiling`
- **照明チャンネル**（照明）
  照明卓で灯体や制御対象を呼び出すための論理的な番号や単位。DMXの一つのスロットとは意味が異なる場合がある。
  ID: `lighting-channel`
- **チェイス**（照明）
  複数の灯体や状態を一定の順序やリズムで次々に変える効果。明るさの点滅だけでなく色や位置の変化も扱う。
  ID: `lighting-chase`
- **CMY減法混色**（照明）
  白色光からシアン・マゼンタ・イエローのフィルターで成分を取り除き色を作る方式。ムービングなどで使う。
  ID: `lighting-cmy`
- **演色性**（照明）
  光で照らされた物の色の見え方に関する性質。衣装や肌の再現に関係し、色温度だけでは判断できない。
  ID: `lighting-colorender`
- **色枠**（照明）
  カラーフィルターや拡散材を灯体の前面に保持する枠。灯体ごとに適合する寸法や構造がある。
  ID: `lighting-colorframe`
- **カラーパレット**（照明）
  灯体の色に関する設定をまとめた参照データ。複数キューで共通の色を使い、色合わせをまとめて修正する。
  ID: `lighting-colorpalette`
- **カラーホイール**（照明）
  複数の色フィルターを円盤に配置し、光路に選択して入れる機構。連続混色方式とは動作や中間色の作り方が異なる。
  ID: `lighting-colorwheel`
- **照明卓**（照明）
  灯体の明るさ、色、位置などを制御し、キューや各種データを作成・再生する操作装置。
  ID: `lighting-console`
- **不滅電源**（照明）
  照明卓の調光に連動して電源が絞られない供給系統を指す現場語。常時給電の範囲や主電源の扱いは、施設の設備によって異なる。
  ID: `lighting-constantpower`
- **平均演色評価数**（照明）
  光源による色の見え方を基準光と比較して平均化した指標。一般にRaで示すが、すべての色の再現性を単独で表せない。
  ID: `lighting-cri`
- **クロスフェード**（照明）
  前の照明状態から次の状態へ移るとき、下がる光と上がる光を時間的に重ねて変化させること。
  ID: `lighting-crossfade`
- **CTB**（照明）
  白色光の色温度を高い側へ補正する青系フィルターの呼称。舞台演出の青色フィルターすべてを指すわけではない。
  ID: `lighting-ctb`
- **CTO**（照明）
  白色光の色温度を低い側へ補正するアンバー系フィルターの呼称。強度をフル、ハーフなどで区分する。
  ID: `lighting-cto`
- **照明キュー**（照明）
  公演の所定の時点で再生する照明の状態や変化の指示。灯体の値と変化にかかる時間などを記録する。
  ID: `lighting-cue`
- **キューリスト**（照明）
  複数の照明キューを順序や再生条件とともにまとめたもの。公演の進行に沿って手動または自動で再生する。
  ID: `lighting-cuelist`
- **キューオンリー**（照明）
  修正や記録の影響を特定のキューに限定し、後続への引き継ぎを抑えるための操作やモード。
  ID: `lighting-cueonly`
- **調光カーブ**（照明）
  入力した制御値と出力の変化との関係を決める特性。明るさの立ち上がりや変化の感覚を調整するために使う。
  ID: `lighting-curve`
- **ホリゾントライト**（照明）
  ホリゾント幕や背景面を広く均一に照らすための器具。上方・床面など設置位置に応じた配光を持つ。
  ID: `lighting-cyc`
- **ディフュージョン**（照明）
  光を散らし、影や照射範囲の境界、光の広がりを調整する素材や効果。透明な色フィルターとは目的が異なる。
  ID: `lighting-diffusion`
- **ディマー**（照明）
  灯体の明るさを変える調光装置、または灯体内の明るさ制御を指す呼称。電源回路の方式と制御項目を区別する。
  ID: `lighting-dimmer`
- **DMX512**（照明）
  照明機器や周辺装置の制御データを送るためのデジタル通信規格。明るさ以外の各種パラメーターも扱う。
  ID: `lighting-dmx`
- **DMXモード**（照明）
  灯体がどの制御項目をどの順序と数で受け取るかを選ぶ設定。モードによって占有するアドレス数などが変わる。
  ID: `lighting-dmxmode`
- **照明エフェクト**（照明）
  明るさ、色、位置などを時間的に変化させるためのプログラム。周期や順序、位相を設定して複数灯体の動きを作る。
  ID: `lighting-effect`
- **フェードイン**（照明）
  時間をかけて照明の明るさを上げる変化。開始点や到達値、時間の設定によって見え方が変わる。
  ID: `lighting-fadein`
- **フェードアウト**（照明）
  時間をかけて照明の明るさを下げる変化。必ずしも全灯を完全消灯するとは限らず、対象と終点を指定する。
  ID: `lighting-fadeout`
- **フィールド角**（照明）
  ビーム角より外側まで含む光の広がりを表す角度。一般に中心光度に対する所定の割合で境界を定める。
  ID: `lighting-fieldangle`
- **灯体**（照明）
  光源やレンズ、反射鏡などを収めた照明器具本体。明るさだけでなく配光や光学機構によって用途が変わる。
  ID: `lighting-fixture`
- **フリッカー**（照明）
  光の明るさが時間的に変動してちらつく現象。肉眼で気付かなくても撮影映像に縞や明滅として現れることがある。
  ID: `lighting-flicker`
- **フラッドライト**（照明）
  広い範囲に光を拡散して照らす器具。輪郭を細かく切る投影用スポットとは光学構造や用途が異なる。
  ID: `lighting-flood`
- **フォーカス**（照明）
  灯体の照射位置、大きさ、輪郭などを目的に合わせる作業。光学系の像のピントだけを指す場合もある。
  ID: `lighting-focus`
- **フォロー**（照明）
  キューの実行後、所定の時間で次のキューを自動開始させる設定。どの時点を計時の基準にするかが重要になる。
  ID: `lighting-follow`
- **フォロースポット**（照明）
  動く出演者などを追尾して照らすスポット。人が直接操作する方式のほか遠隔操作する方式もある。
  ID: `lighting-followspot`
- **フットライト**（照明）
  舞台前端や花道沿いの床付近から演者を照らす照明。足元から上がる特徴的な陰影を作る。
  ID: `lighting-foot`
- **フットプリント**（照明）
  ある機器が選択したモードで占有するDMXスロット数。多機能な灯体では複数の制御値をまとめて使う。
  ID: `lighting-footprint`
- **フレネルスポット**（照明）
  同心円状の溝を持つフレネルレンズを用いるスポット。柔らかい輪郭の光を作り、地明かりなどに使う。
  ID: `lighting-fresnel`
- **フロントライト**（照明）
  出演者の客席側から当てる光。顔を見せる役割を担い、上下左右の角度によって影や立体感が変わる。
  ID: `lighting-frontlight`
- **フロントサイド**（照明）
  客席の左右側面から舞台へ斜め前方の光を送る照射位置。日本の劇場設備図ではFRなどの略号を使う。
  ID: `lighting-frontside`
- **カラーフィルター**（照明）
  灯体の光に色を付けたり色味を補正したりする透過素材。製品系列ごとに色番号や特性が異なる。
  ID: `lighting-gel`
- **地明かり**（照明）
  演技する範囲を広く支える基礎の照明。特定の人物や装置だけを狙う明かりと組み合わせて舞台の状態を作る。
  ID: `lighting-generalwash`
- **グレア**（照明）
  強い光や明暗差によって、まぶしさや見えにくさが生じること。客席から灯体が直接見える状況などに関係する。
  ID: `lighting-glare`
- **GO**（照明）
  待機している照明キューなどを開始する操作や合図。具体的にどの再生対象を進めるかは卓の割り当てで決まる。
  ID: `lighting-go`
- **ゴボ**（照明）
  灯体の光学系に入れて模様や文字などを投影する金属・ガラス製などのパターン。サイズや耐熱条件は器種に合うものを使う。
  ID: `lighting-gobo`
- **ゴボインデックス**（照明）
  ゴボの回転角を一定の位置へ指定する機能。連続回転とは異なり、模様や文字の向きを固定するために使う。
  ID: `lighting-goboindex`
- **ゴボローテーター**（照明）
  ゴボを回転させるための機構やアクセサリー。回転速度や方向、角度を制御して模様に動きを与える。
  ID: `lighting-goborotate`
- **グランドマスター**（照明）
  対象となる照明出力全体などの明るさに上限や比率をかける総括制御。除外対象や適用範囲は卓の設定による。
  ID: `lighting-grandmaster`
- **ハング**（照明）
  現在のキューの変化が完了してから、次のキューを開始するまでの時間を扱う設定。フォローと基準時点が異なる。
  ID: `lighting-hang`
- **ハードライト／ソフトライト**（照明）
  影や照射範囲の境界が明瞭な光と、柔らかい光を区別する表現。光源の見かけの大きさや光学系などが影響する。
  ID: `lighting-hardsoft`
- **ヘイズ**（照明）
  空間に薄く広がる演出用の霧状効果。光線を空中に見せる用途などに使い、濃い霧や低く漂う効果とは区別する。
  ID: `lighting-haze`
- **HTP**（照明）
  同じ制御対象に複数の値が来たとき、最も高い値を優先する考え方。主に明るさの合成に使う。
  ID: `lighting-htp`
- **色相**（照明）
  赤や青など色の種類を区別する性質。照明卓のカラーピッカーなどでは彩度などと組み合わせて使う。
  ID: `lighting-hue`
- **照度**（照明）
  ある面に入る光束の単位面積当たりの量。ルクスで表し、灯体自体の出力を表す光束とは区別する。
  ID: `lighting-illuminance`
- **インテンシティ**（照明）
  照明卓で灯体の明るさを扱う制御項目。通常パーセントなどで指定し、照度や物理的な光度とは区別する。
  ID: `lighting-intensity`
- **光度**（照明）
  光源から特定の方向に出る光束の立体角当たりの量。カンデラで表し、光の方向性を扱う。
  ID: `lighting-intensitycd`
- **アイリス**（照明）
  羽根を連動させて円形の開口を変え、照射範囲を絞る光学機構。フォロースポットや一部の灯体に備わる。
  ID: `lighting-iris`
- **LED照明**（照明）
  発光ダイオードを光源とする照明。光色、調光特性、撮影時のちらつきなどは機種や制御方式で変わる。
  ID: `lighting-led`
- **LEDバー**（照明）
  LED光源を直線状に配置した器具。面を染めたり、個別セルの制御で動きのある効果を作ったりする。
  ID: `lighting-ledbar`
- **レンズチューブ**（照明）
  プロファイルスポットなどで投影レンズを保持する部分。交換式ではレンズの選択によって照射角が変わる。
  ID: `lighting-lens`
- **ライブ**（照明）
  照明卓で現在の舞台出力を扱う操作領域やモード。操作が舞台の見た目に反映されるため、編集中の対象を確認する。
  ID: `lighting-live`
- **ロアーホリゾント**（照明）
  ホリゾント幕を床付近から照らす照明。背景下部からの色や明るさを作る用途に使われる。
  ID: `lighting-lowercyc`
- **LTP**（照明）
  同じ制御対象へ複数の指示が来たとき、最新の指示を優先する考え方。位置や色などの制御にも使う。
  ID: `lighting-ltp`
- **輝度**（照明）
  ある方向から見た面の輝きの度合いを表す測光量。光が面へ入る量を示す照度とは異なる。
  ID: `lighting-luminance`
- **光束**（照明）
  人の目の感度を考慮した光の量。ルーメンで表し、ある面に届く光の量を表す照度とは異なる。
  ID: `lighting-luminousflux`
- **マーク**（照明）
  灯体が消灯中などに、次の点灯に備えて色や向きをあらかじめ整える制御。移動や色替えを見せないために使う。
  ID: `lighting-mark`
- **マイナスグリーン**（照明）
  光の緑かぶりを抑えるためのマゼンタ系補正フィルター。肌や白い物の色合わせなどに使う。
  ID: `lighting-minusgreen`
- **ムービングライト**（照明）
  向きや色、ビーム形状などを遠隔制御できる灯体の総称。機種ごとに搭載する機能や必要な制御数が異なる。
  ID: `lighting-moving`
- **NDフィルター**（照明）
  色味への影響を抑えながら光量を減らすフィルター。灯体の調光だけでは得にくい条件を調整する場合に使う。
  ID: `lighting-nd`
- **DMXノード**（照明）
  ネットワーク上の照明制御データと物理DMXなどを橋渡しする機器。入出力数や対応プロトコルは製品ごとに異なる。
  ID: `lighting-node`
- **生**（照明）
  日本の照明現場で、色フィルターを通さない灯体の光を指す呼称。光源そのものの色味は残る。
  ID: `lighting-openwhite`
- **パレット**（照明）
  色や位置など、再利用する灯体の設定を参照データとして記録するもの。参照先の修正を複数キューへ反映できる。
  ID: `lighting-palette`
- **パン**（照明）
  ムービングライトの主に水平方向の回転を表す制御項目。チルトと組み合わせて照射方向を指定する。
  ID: `lighting-pan`
- **PARライト**（照明）
  伝統的には反射鏡・光源・レンズを一体化したPARランプを用いる器具。LED型もPARの名称で流通する。
  ID: `lighting-par`
- **パッチ**（照明）
  卓上のチャンネルと実際の出力アドレスや灯体の種類などを対応させる設定。物理配線を指す場合もある。
  ID: `lighting-patch`
- **ピクセルマッピング**（照明）
  灯体や発光セルを画素のように配置し、画像や映像などの内容に合わせて明るさや色を制御する手法。実際の配列とデータを対応させる。
  ID: `lighting-pixelmapping`
- **プレイバック**（照明）
  記録したキューリストなどを再生する機能や、その操作部。フェーダーやボタンへの割り当て方法は卓による。
  ID: `lighting-playback`
- **照明仕込み図**（照明）
  灯体の種類、取付位置、向き、番号、色などを図面上に示した資料。仕込みや調整の共通情報として使う。
  ID: `lighting-plot`
- **プラスグリーン**（照明）
  光に緑方向の色味を加える補正フィルター。既存光源との色合わせや、撮影時の光源間の調整などに使う。
  ID: `lighting-plusgreen`
- **ポジションパレット**（照明）
  ムービングの向きなどの位置情報を再利用する参照データ。会場変更時などに共通の照射位置をまとめて調整できる。
  ID: `lighting-positionpalette`
- **プリセット**（照明）
  事前に記録した灯体設定などを呼び出すデータ。色や位置をまとめるか項目ごとに分けるかは卓の設計による。
  ID: `lighting-preset`
- **プリズム**（照明）
  灯体内などに入れ、光束やゴボ像を複数に分ける光学部品。回転や重ね合わせができる製品もある。
  ID: `lighting-prism`
- **プロファイルスポット**（照明）
  明瞭な輪郭を作り、シャッターで形を切ったりゴボを投影したりできるスポット。米英で呼び方に違いがある。
  ID: `lighting-profile`
- **フィクスチャープロファイル**（照明）
  灯体のDMX配置や各制御値の意味を卓へ知らせる定義データ。機種名だけでなく動作モードまで一致させる。
  ID: `lighting-profiledata`
- **PWM調光**（照明）
  点灯している時間の割合を変えるなどして明るさを調整する方式。LEDの撮影時のちらつきに関係することがある。
  ID: `lighting-pwm`
- **RDM**（照明）
  DMX回線上で対応機器と双方向にやり取りし、機器情報の取得や設定などを行う仕組み。ANSI E1.20に基づく。
  ID: `lighting-rdm`
- **RDMnet**（照明）
  IPネットワーク上で照明機器の管理やRDM関連メッセージを扱うための規格。sACNとは役割が異なる。
  ID: `lighting-rdmnet`
- **RGB加法混色**（照明）
  赤・緑・青の光を重ねて色を作る方式。LED灯体などで用い、成分を足す方向に混色する。
  ID: `lighting-rgb`
- **sACN**（照明）
  DMX512のデータをIPネットワーク上で運ぶための制御プロトコル。ANSI E1.31として規定される。
  ID: `lighting-sacn`
- **彩度**（照明）
  色の鮮やかさや白色との混ざり具合を扱う表現。照明卓では色相と組み合わせて色を指定する場合がある。
  ID: `lighting-saturation`
- **シンライト**（照明）
  舞台袖の低い位置から横に当てる光。床を避けて身体を照らし、舞踊の立体感や浮遊感を作る。
  ID: `lighting-shin`
- **フレーミングシャッター**（照明）
  プロファイル系の灯体内で光の輪郭を切り取る機構。複数の羽根で四角形などの照射範囲を作る。
  ID: `lighting-shutter`
- **サイドライト**（照明）
  出演者を横方向から照らす光。身体の立体感や動きを強調し、特に舞踊などでよく用いられる。
  ID: `lighting-sidelight`
- **スモーク**（照明）
  煙状の霧などを発生させ、光の筋や空間の雰囲気を見せる舞台効果。霧の密度や持続性などは、機器と使用する液剤で異なる。
  ID: `lighting-smoke`
- **スペシャル**（照明）
  特定の場所、人物、装置や効果のために用意する専用の照明。舞台全体を照らす基礎照明と区別して計画する。
  ID: `lighting-special`
- **スピル**（照明）
  意図した照射範囲の外へ漏れたり回り込んだりする光。袖幕、背景、客席などへの不要な光を指す。
  ID: `lighting-spill`
- **DMXスプリッター**（照明）
  DMX信号を複数の系統へ分配する機器。ポート間の絶縁やRDMへの対応は製品により異なる。
  ID: `lighting-splitter`
- **スポット型ムービング**（照明）
  比較的輪郭の明確な光やゴボ投影を中心に使うムービングライト。フレーミング機構の有無は機種による。
  ID: `lighting-spotmoving`
- **ステージサイド**（照明）
  舞台袖から演者や装置へ横方向の光を送る照明。日本ではステージサイドスポットをSSと略すことがある。
  ID: `lighting-ss`
- **ボーダーライト**（照明）
  複数の光源を横長に配置した照明器具。舞台上方から広い範囲を照らす用途などに使われる。
  ID: `lighting-strip`
- **ストロボ**（照明）
  光を繰り返し短く点滅させる演出や機能。専用灯体のほかムービングやLED灯体にも備わる。
  ID: `lighting-strobe`
- **サブマスター**（照明）
  複数の灯体や記録した状態をまとめて扱う制御部。加算や抑制などの動作方式は卓や設定によって異なる。
  ID: `lighting-submaster`
- **サスペンションライト**（照明）
  舞台上方の吊り位置に設置する照明。日本では吊りバトンの列を第一サス、第二サスなどと呼ぶ。
  ID: `lighting-sus`
- **チルト**（照明）
  ムービングライトの主に上下方向の回転を表す制御項目。パンと組み合わせて光の向きを指定する。
  ID: `lighting-tilt`
- **トップライト**（照明）
  対象物のほぼ真上から当てる光。床に範囲を作りやすく、顔や身体には上方向からの強い陰影が生じる。
  ID: `lighting-toplight`
- **トラッキング**（照明）
  あるキューで変えた値を、次の変更指示などが現れるまで後続のキューへ引き継ぐ考え方。
  ID: `lighting-tracking`
- **タングステン光源**（照明）
  タングステンのフィラメントを加熱して発光する光源。舞台ではハロゲン電球も含めて呼ぶことがある。
  ID: `lighting-tungsten`
- **ユニバース**（照明）
  DMXの制御データをまとめる単位。通常一つのユニバースは最大512スロットの制御値を扱う。
  ID: `lighting-universe`
- **アップライト**（照明）
  低い位置から上方向に当てる光。壁や装置を染めたり、顔に普段と異なる陰影を作ったりする。
  ID: `lighting-uplight`
- **アッパーホリゾント**（照明）
  ホリゾント幕を上方から照らす照明。下方からの照明と組み合わせ、背景の色や明るさを整える。
  ID: `lighting-uppercyc`
- **ウォッシュ**（照明）
  ある面や範囲を広く覆う照明の状態や用途。灯体の種類名にも使われるが、特定の光源方式を意味しない。
  ID: `lighting-wash`
- **ウォッシュ型ムービング**（照明）
  舞台面を柔らかく広く染める用途を中心に設計されたムービングライト。ズームや色混合などの機能を持つ。
  ID: `lighting-washmoving`
- **ズーム**（照明）
  灯体の照射角を変え、照射範囲の大きさを調整する光学機能。像のピントを調整するフォーカスとは別の働き。
  ID: `lighting-zoom`
- **巻き**（制作・運営）
  予定より早く進んでいる状態。また、進行を早めるよう求める指示にも使うため、現状の報告か変更指示かを区別する。
  ID: `production-ahead`
- **ASM**（制作・運営）
  舞台監督チームの補助担当。小道具の準備や袖での進行などを担うが、日本の舞監助手と担当範囲が必ずしも一致しない。
  ID: `production-asm`
- **押し**（制作・運営）
  予定していた時刻より進行が遅れている状態。どの時点の予定と比べて何分遅れているかを示し、連絡に使う。
  ID: `production-behind`
- **立ち稽古**（制作・運営）
  出演者の立ち位置、出入り、移動などを実際に動きながら組み立てる稽古。
  ID: `production-blocking`
- **進行台本**（制作・運営）
  せりふや進行順に、技術キュー・転換・出演者の動きなどを記録した進行用の台本。資料の形式は公演により異なる。
  ID: `production-book`
- **キューシート**（制作・運営）
  音・照明・映像などの実行内容とタイミングをまとめた表。各部門の操作確認や進行の共有に使う。
  ID: `production-cuesheet`
- **演出家**（制作・運営）
  作品の解釈や表現方針を定め、出演者の演技と美術・照明・音響などを統合して上演を構成する担当。
  ID: `production-director`
- **ドレスリハーサル**（制作・運営）
  衣裳やメイク、技術要素を含め、本番に近い状態で行う稽古。ゲネプロとの使い分けは制作現場により異なる。
  ID: `production-dress`
- **DSM**（制作・運営）
  英国の舞台監督チームの役職。台本を追いながら稽古の記録や本番のキュー出しなどを担う体制が一般的。
  ID: `production-dsm`
- **尺**（制作・運営）
  映像・音素材や演目などの時間の長さを指す現場語。開始時刻とは別に、どれだけの時間がかかるかを表す。
  ID: `production-duration`
- **終演**（制作・運営）
  その公演の上演が終わること。観客の退場や装置の撤去が完了する時点とは異なり、公演後の工程と区別して扱う。
  ID: `production-finish`
- **GO**（制作・運営）
  準備されたキューや動作を実行する合図。予告のスタンバイと区別し、現場で定めた呼び方を用いる。
  ID: `production-go`
- **ゲネプロ**（制作・運営）
  本番前の総仕上げとして行う総稽古を指す日本の現場語。ドイツ語 Generalprobe に由来する。
  ID: `production-gp`
- **ハーフアワーコール**（制作・運営）
  英語圏の公演で用いられる、開演まで約30分であることを出演者らに知らせる呼び出し。集合の決まりは公演ごとに異なる。
  ID: `production-halfhour`
- **開場**（制作・運営）
  観客を客席や会場へ入れ始めること。作品の上演が始まる開演とは別の時点で、ロビー開場だけを先に行う場合もある。
  ID: `production-houseopen`
- **香盤**（制作・運営）
  出演者と場面の対応や出番を整理した表。稽古、公演、衣裳や小道具の準備のために用いる。
  ID: `production-kouban`
- **マチネ**（制作・運営）
  昼間、特に午後に行う公演を指す語。フランス語由来で、夕方以降の公演との区別に使う。
  ID: `production-matinee`
- **ペーパーテック**（制作・運営）
  実機での稽古に先立ち、台本上でキューの内容・番号・タイミングなどを関係者で整理する打ち合わせ。
  ID: `production-papertech`
- **プロダクションマネージャー**（制作・運営）
  公演を実現するため、技術部門を横断して工程・人員・予算などを調整する担当。舞台監督とは分担して働く。
  ID: `production-pm`
- **キュートゥキュー**（制作・運営）
  技術キューがある箇所を中心に、間を省略しながら進める稽古。全編を連続して行う通し稽古とは目的が異なる。
  ID: `production-qtoq`
- **通し稽古**（制作・運営）
  作品全体や一定のまとまりを、進行順に続けて行う稽古。必ずしも衣裳や技術要素がすべて揃う段階とは限らない。
  ID: `production-run`
- **ジッツプローベ**（制作・運営）
  オペラやミュージカルで、主に演技の動きをつけず歌手とオーケストラの音楽を合わせる稽古。ドイツ語由来。
  ID: `production-sitz`
- **舞台監督**（制作・運営）
  稽古と本番の進行を支え、出演者と技術各部門をつなぐ担当。具体的な職務や権限は公演・国・組織により異なる。
  ID: `production-sm`
- **スタンバイ**（制作・運営）
  間もなく実行する操作や出演に備えるよう知らせる予告。通常、実行そのものの合図とは区別する。
  ID: `production-standby`
- **開演**（制作・運営）
  公演の上演を始めること。観客の入場を始める開場と区別し、台本や案内では実際に上演が始まる時点を示す。
  ID: `production-start`
- **テクニカルリハーサル**（制作・運営）
  照明・音響・映像・転換などの技術要素と出演者の動きを合わせ、キューや進行を確認する稽古。
  ID: `production-tech`
- **場当たり**（制作・運営）
  本番の舞台で立ち位置や出入り、装置との関係、技術上のきっかけなどを確認する作業。全編を連続して演じる稽古とは限らない。
  ID: `production-walkthrough`
- **仕込み**（安全・仕込み）
  公演のために装置や機材を所定の位置へ設置し、使用できる状態を整える作業の総称。
  ID: `safety-fitup`
- **高所作業**（安全・仕込み）
  落下によって負傷するおそれのある位置で行う作業。劇場では作業床、脚立、昇降設備などが関係する。
  ID: `safety-height`
- **搬入**（安全・仕込み）
  公演に使う装置や機材を会場内へ運び入れること。現場への設置を指す仕込みとは作業の範囲が異なる。
  ID: `safety-loadin`
- **搬出**（安全・仕込み）
  公演で使用した装置や機材を会場の外へ運び出すこと。解体・撤去と運搬の工程を分けて考えることもある。
  ID: `safety-loadout`
- **人力運搬**（安全・仕込み）
  人の力で荷物を持ち上げる、下ろす、押す、引く、運ぶなどの取り扱い。舞台装置や機材の移動にも関係する。
  ID: `safety-manual`
- **点荷重**（安全・仕込み）
  ある一点または局所に集中して加わる荷重。広い範囲に分散して加わる荷重と区別する。
  ID: `safety-pointload`
- **PPE**（安全・仕込み）
  作業する人が身に着ける保護具の総称。必要な種類は危険源や作業内容によって異なる。
  ID: `safety-ppe`
- **救助計画**（安全・仕込み）
  事故や設備停止などで自力で移動できない人を救助するための事前の計画。特に高所作業で重要になる。
  ID: `safety-rescue`
- **リギング**（安全・仕込み）
  装置や機材を吊り、支持し、必要に応じて昇降させるための仕組みや関連作業。単なるロープ結びだけを指す語ではない。
  ID: `safety-rigging`
- **リスクアセスメント**（安全・仕込み）
  作業の危険源を特定し、起こりやすさと影響などを評価して対策を検討すること。
  ID: `safety-risk`
- **二次落下防止**（安全・仕込み）
  主な取付部が機能しなくなった場合に備え、機材などの落下を抑えるために設ける独立した保持。
  ID: `safety-secondary`
- **シャックル**（安全・仕込み）
  弓形などの本体とピンで構成され、吊り具や荷の接続に使われる金具。形状や表示は用途によって異なる。
  ID: `safety-shackle`
- **スリング**（安全・仕込み）
  荷と吊り上げ機器の間に用いる吊り具。繊維、ワイヤーロープ、チェーンなどの種類がある。
  ID: `safety-sling`
- **バラシ**（安全・仕込み）
  仕込んだ装置・機材などを解体して撤去する作業。搬出を含めて呼ぶ場合もあり、工程名の範囲を確認する。
  ID: `safety-strike`
- **SWL**（安全・仕込み）
  所定の条件で機材や設備を安全に扱うために示される荷重。構成や使用条件によって値が変わる場合がある。
  ID: `safety-swl`
- **演技区域**（舞台・劇場）
  演者が観客に見せる演技を行う範囲。舞台の建築的な広さと同一ではなく、美術や照明、客席配置によって決まる。
  ID: `stage-actingarea`
- **揚幕**（舞台・劇場）
  歌舞伎では花道の突き当たり、鳥屋の入口に掛ける幕。能では橋掛りの端に掛かる幕を同じ名で呼ぶ。
  ID: `stage-agemaku`
- **前舞台**（舞台・劇場）
  プロセニアムより客席側へ張り出した演技区域。舞台本体と続いていて、観客に近い位置で演じるために使われる。
  ID: `stage-apron`
- **アリーナステージ**（舞台・劇場）
  中央の演技区域を周囲の観客が囲む舞台形式。大規模な段床客席を持つ会場にも使われ、円形の舞台に限らない。
  ID: `stage-arena`
- **後座**（舞台・劇場）
  能舞台で本舞台の奥に続く部分。囃子方や後見の場所として使われ、床板の向きから横板とも呼ばれる。
  ID: `stage-atoza`
- **客席**（舞台・劇場）
  観客が公演を見るための座席や区域。舞台、ホワイエ、楽屋などと区分され、英語では House とも呼ばれる。
  ID: `stage-auditorium`
- **背景幕**（舞台・劇場）
  風景や室内などを描いて場面の背景にする幕。無地の幕を照らす方法とは別に、絵そのものが場所や空間を示す。
  ID: `stage-backdrop`
- **かがみ**（舞台・劇場）
  道具の扉や窓の奥に置き、開口から舞台裏が見えないようにする張物など。反射する鏡とは別の大道具用語。
  ID: `stage-backing`
- **バックヤード**（舞台・劇場）
  舞台裏、楽屋、スタッフの作業区域など、主に公演関係者が使う空間の総称。客席側の共用区域と区別して用いる。
  ID: `stage-backstage`
- **バルコニー席**（舞台・劇場）
  主階席より上の階に張り出した客席。劇場により階層名が異なり、英米でも Balcony、Mezzanine、Circle などを使い分ける。
  ID: `stage-balcony`
- **バトン**（舞台・劇場）
  幕や大道具、照明などを吊るための横長の棒状部材。舞台上方から吊られ、公演の仕込み位置の基準にもなる。
  ID: `stage-batten`
- **大黒幕**（舞台・劇場）
  舞台後方を大きく覆う黒い幕。奥の設備や空間を隠し、演技や舞台美術の背景を黒でまとめるために使う。
  ID: `stage-blackbackdrop`
- **ブラックボックス**（舞台・劇場）
  舞台や客席を固定せず、公演に合わせて柔軟に配置する上演空間。黒い内装が典型だが、名称の要点は可変性にある。
  ID: `stage-blackbox`
- **暗転幕**（舞台・劇場）
  暗転中の場面転換を客席から隠すために使う幕。幕の奥で作業し、次の場面を見せるタイミングを整える。
  ID: `stage-blackoutcurtain`
- **ブロッキング**（舞台・劇場）
  舞台上の立ち位置や移動、相手との位置関係を組み立てること。演出上の動きを稽古で決め、記録して共有する。
  ID: `stage-blocking`
- **一文字幕**（舞台・劇場）
  舞台上部に横長に吊り、上方の設備や幕の吊元を隠す幕。左右の袖幕と組み合わせて、観客から見える範囲を整える。
  ID: `stage-border`
- **ボックスセット**（舞台・劇場）
  室内の壁を囲うように構成する舞台装置。三方の壁などによって室内を示し、客席側を開いて演技を見せる。
  ID: `stage-boxset`
- **人形立て**（舞台・劇場）
  張物やパネルを背面から支える部材。平面の装置を舞台上で立てて配置する際に用い、形状や構造はさまざま。
  ID: `stage-brace`
- **壊し道具**（舞台・劇場）
  場面の中で壊れることを演出するために製作する小道具や装置。通常の実用品とは別の、美術・演出用の物を指す。
  ID: `stage-breakaway`
- **センター**（舞台・劇場）
  舞台や演技区域の中央。左右の中央だけを指す場合と、奥行きも含む中央を指す場合があり、図面で位置を確かめる。
  ID: `stage-centre`
- **芯**（舞台・劇場）
  舞台や道具の位置を決める基準となる中心線。舞台の左右位置を測る際は、舞台芯からの距離で示すことが多い。
  ID: `stage-centreline`
- **消え物**（舞台・劇場）
  食べ物や飲み物など、公演中の使用によって消費・変化し、補充や作り直しが必要になる小道具。場面ごとに準備数を管理する。
  ID: `stage-consumableprops`
- **鎮**（舞台・劇場）
  吊物の重さとの釣り合いを取るために用いる重り。カウンターウェイト式の吊物機構を構成する要素の一つ。
  ID: `stage-counterweight`
- **クロスオーバー**（舞台・劇場）
  客席から見えないまま舞台の片側から反対側へ移動する通路。舞台後方や舞台下など、劇場によって経路が異なる。
  ID: `stage-crossover`
- **カーテンコール**（舞台・劇場）
  終演後、観客の拍手に応えて出演者が舞台上で挨拶すること。幕の有無にかかわらず用いられる。
  ID: `stage-curtaincall`
- **カットクロス**（舞台・劇場）
  輪郭や開口を切り抜いて作る背景用の布。必要に応じてネットなどで支え、木立や建物の間から奥の景色を見せる。
  ID: `stage-cutcloth`
- **ホリゾント幕**（舞台・劇場）
  舞台後方に広く設け、空や色面などの背景を作る幕。照明や映像の当て方で、奥行きや時間の変化を表現する。
  ID: `stage-cyclorama`
- **暗転**（舞台・劇場）
  舞台を暗くすること。また、暗くした状態で行う場面転換を指す。照明キューだけを示す場合と、転換全体を示す場合がある。
  ID: `stage-darkchange`
- **舞台床**（舞台・劇場）
  演技や舞台装置の設置に使う舞台の床面。常設の床と公演用に上から設ける床を区別して扱うことがある。
  ID: `stage-deck`
- **奥行**（舞台・劇場）
  舞台や舞台装置の前後方向の長さ。どの線からどこまでを測るかによって値が変わるため、基準線と一緒に示す。
  ID: `stage-depth`
- **遠見**（舞台・劇場）
  遠方の景色を表す背景や装置。近景の道具の奥に置き、絵や縮尺の違いによって遠い空間を感じさせる。
  ID: `stage-distantview`
- **舞台前**（舞台・劇場）
  舞台のうち客席に近い側、またはその方向。舞台奥と対になる呼び方で、舞台床の高低そのものは表さない。
  ID: `stage-downstage`
- **楽屋**（舞台・劇場）
  出演者が衣装や化粧を整え、出番まで待機する部屋。共有の休憩室である Green room とは機能が異なる。
  ID: `stage-dressingroom`
- **舞台端**（舞台・劇場）
  舞台床の客席側の端。舞台前方という広い区域とは異なり、床の終わりに当たる境界を指す。
  ID: `stage-edge`
- **可動プロセニアム**（舞台・劇場）
  舞台の見える開口幅や高さを調整するための可動の枠。固定の建築開口の内側に設け、公演に合わせて見え方を変える。
  ID: `stage-falseproscenium`
- **蹴込み**（舞台・劇場）
  平台や二重の前面・側面に付け、脚や床下の空間を客席から隠す部分。板や布など、公演に合う素材を使う。
  ID: `stage-fascia`
- **張物**（舞台・劇場）
  木などの枠に板や布を張った、壁や背景に使う平面的な舞台装置。開口を設けて扉や窓を組み込むこともある。
  ID: `stage-flat`
- **地がすり**（舞台・劇場）
  舞台床を覆うように敷く布。床の色や質感を場面に合わせたり、既存の床面を視覚的にまとめたりする。
  ID: `stage-floorcloth`
- **降ろす**（舞台・劇場）
  吊られた幕や道具を下げ、必要な位置へ入れること。床へ下ろす場合と、演出用の高さへ下げる場合を区別する。
  ID: `stage-flyin`
- **フライング**（舞台・劇場）
  演者を吊り、空中を移動したり浮いて見えたりする表現を作る舞台効果。道具の昇降を指す flying と対象を区別する。
  ID: `stage-flyingperformer`
- **吊物**（舞台・劇場）
  バトンなどから吊り下げる幕や大道具の総称。上下に動かして見せ隠しし、舞台の空間や場面を変える。
  ID: `stage-flyingscenery`
- **フライ担当**（舞台・劇場）
  幕や道具の吊物を扱う担当者。舞台進行に合わせた昇降や、吊物機構に関する作業を受け持つ。
  ID: `stage-flyoperator`
- **飛ばす**（舞台・劇場）
  幕や道具などの吊物を上昇させ、観客の視界から外すこと。台本の一部を省く意味でも使うため、対象を添える。
  ID: `stage-flyout`
- **フライタワー**（舞台・劇場）
  舞台の上方にあり、吊った幕や道具を観客の視界外へ収めるための高い空間。劇場全体の舞台機構の一部をなす。
  ID: `stage-flytower`
- **フロントオブハウス**（舞台・劇場）
  劇場のうち観客に開かれた区域、または接客・客席管理部門。音響や照明では客席側の設置位置を指す用法もある。
  ID: `stage-foh`
- **ホワイエ**（舞台・劇場）
  客席の外側にあり、開演前や休憩中に観客が滞在する共用空間。受付、飲食、展示などの機能を備える場合もある。
  ID: `stage-foyer`
- **振り被せ**（舞台・劇場）
  巻くなどして上部に収めた幕を、きっかけで展開して場面を覆ったり背景を変えたりする演出。幕を外して落とす振り落としと区別する。
  ID: `stage-furikabuse`
- **振り落とし**（舞台・劇場）
  吊られた幕をきっかけに合わせて落下させ、奥の場面を一度に見せる演出。また、そのための幕の仕掛けを指す。
  ID: `stage-furiotoshi`
- **グリーンルーム**（舞台・劇場）
  出演者などが舞台裏で休憩・待機する共用の部屋。着替えを行う楽屋とは別に設けられる場合がある。
  ID: `stage-greenroom`
- **すのこ**（舞台・劇場）
  舞台の高所にある格子状の作業床や構造。吊物機構の滑車などを配置する場所として使われる。
  ID: `stage-grid`
- **舞台平面図**（舞台・劇場）
  舞台や道具の配置を上から見た図。開口、壁、床、立ち位置などを縮尺と基準線に沿って示し、各部署の計画を共有する。
  ID: `stage-groundplan`
- **箱馬**（舞台・劇場）
  平台などを支え、床面の高さを作るための箱状の部材。日本の舞台で用いられ、同じ呼称でも寸法や構造は一律ではない。
  ID: `stage-hakouma`
- **花道**（舞台・劇場）
  歌舞伎で舞台の下手側から客席の中を通り、後方の鳥屋につながる通路状の舞台。登退場だけでなく独立した演技にも使う。
  ID: `stage-hanamichi`
- **持道具**（舞台・劇場）
  演者が手に持ったり身に付けたりして扱う小道具。場面内の受け渡しや、出番ごとの準備位置を管理する。
  ID: `stage-handprops`
- **橋掛り**（舞台・劇場）
  能舞台の本舞台と鏡の間を結ぶ通路状の部分。登退場の経路であるとともに、本舞台とは別の場所を表す演技空間にもなる。
  ID: `stage-hashigakari`
- **たっぱ**（舞台・劇場）
  大道具や建具などの高さを指す現場語。「立端」などと表記し、物の高さか、吊り位置の高さかを文脈で区別する。
  ID: `stage-height`
- **開き足**（舞台・劇場）
  平台を所定の高さで支えるための、開閉する脚の部材。箱馬などとともに、日本の舞台で台組みに使われる。
  ID: `stage-hirakiashi`
- **ハウスレフト**（舞台・劇場）
  客席に座って舞台を向いたときの左側。演者の向きを基準にする Stage left とは逆で、通常は下手側に当たる。
  ID: `stage-houseleft`
- **ハウスライト**（舞台・劇場）
  客席に座って舞台を向いたときの右側。演者の向きを基準にする Stage right とは逆で、通常は上手側に当たる。
  ID: `stage-houseright`
- **地謡座**（舞台・劇場）
  能舞台の本舞台に接して設けられる、地謡の演者が座る部分。観客から見て本舞台の右側に位置する。
  ID: `stage-jiutaiza`
- **定式幕**（舞台・劇場）
  歌舞伎で場面の始まりや終わりに引いて使う幕。黒・萌葱・柿色の縦縞が典型で、色の並びは劇場により異なる。
  ID: `stage-joshikimaku`
- **鏡板**（舞台・劇場）
  能舞台の奥にある板壁で、松が描かれている部分。能の舞台空間を特徴付ける背景で、公演ごとに交換する写実的背景とは異なる。
  ID: `stage-kagamiita`

  時間情報を連続した信号として記録・伝送するタイムコードの方式。音声用の経路を利用して扱われることがある。
  ID: `video-ltc`
- **プロジェクションマッピング**（映像・制御）
  立体物や舞台装置の形状・位置に合わせて映像を変形し、投影範囲を割り当てる表現手法。
  ID: `video-mapping`
- **MIDI**（映像・制御）
  演奏情報などを機器間で伝える規格群。音声そのものではなく、ノートや制御値などの情報を扱う。
  ID: `video-midi`
- **MSC**（映像・制御）
  MIDI の仕組みを使い、GO や停止などのショー制御命令を機器間でやり取りする方式。MTC とは役割が異なる。
  ID: `video-msc`
- **MTC**（映像・制御）
  MIDI メッセージで時間位置を伝える方式。ショーの時間同期に使われ、GO 命令を送る MSC とは異なる。
  ID: `video-mtc`
- **マルチビュー**（映像・制御）
  複数の入力やプログラム、プレビューなどを一つの画面に分割表示する監視機能。
  ID: `video-multiview`
- **NDI**（映像・制御）
  IP ネットワーク上で映像・音声・メタデータをやり取りする技術群。単独のコーデック名ではなく、形式により帯域や遅延が異なる。
  ID: `video-ndi`
- **OSC**（映像・制御）
  アドレスと引数を持つメッセージでソフトウェアや機器を制御する形式。音響に限らず照明・映像の連携にも使われる。
  ID: `video-osc`
- **プレイヘッド**（映像・制御）
  現在の再生位置や次に実行するキューの位置を示すもの。タイムライン方式とキュー方式で表示の意味が異なる。
  ID: `video-playhead`
- **ポストウェイト**（映像・制御）
  キュー本体の開始後から自動継続までの待ち時間を示す設定。QLab ではキュー本体の終了から数える時間とは限らない。
  ID: `video-postwait`
- **プレビュー**（映像・制御）
  本番出力へ切り替える前に確認する映像や出力。プログラムとは別に、次に使用する素材を点検できる。
  ID: `video-preview`
- **プリウェイト**（映像・制御）
  キューを起動してから、その内容の実行が始まるまでに設ける待ち時間。主にキュー再生ソフトの用語。
  ID: `video-prewait`
- **プログラム**（映像・制御）
  スイッチャーで実際に送出中の映像、またはその出力系統。公演の演目表を意味するプログラムとは文脈が異なる。
  ID: `video-program`
- **プロジェクター**（映像・制御）
  光学系を使って映像をスクリーンや舞台面へ投影する機器。設置条件、明るさ、レンズの選定が画面に影響する。
  ID: `video-projector`
- **解像度**（映像・制御）
  デジタル映像や画面を構成する画素の数。横と縦の画素数で表すことが多く、画面の縦横比やフレームレートとは別の情報。
  ID: `video-resolution`
- **SDI**（映像・制御）
  業務用のデジタル映像信号を伝送するインターフェース。同軸ケーブルや光伝送の構成があり、対応する信号形式は機器により異なる。
  ID: `video-sdi`
- **メディアサーバー**（映像・制御）
  複数の映像素材の再生・合成・出力を管理するシステム。舞台映像ではキューや外部制御と連携させることがある。
  ID: `video-server`
- **ステージ（映像）**（映像・制御）
  QLab 5 で映像キューを配置する仮想的な画面。実際の舞台や、旧版のサーフェスという名称と区別して用いる。
  ID: `video-stage`
- **サーフェス**（映像・制御）
  映像を配置・出力する面を表す語。実際の投影面を指す場合と、ソフトウェア内部の仮想面を指す場合がある。
  ID: `video-surface`
- **映像スイッチャー**（映像・制御）
  複数の映像入力から出力する映像を選び、切替や合成を行う機器。音響のミキサーとは扱う主信号が異なる。
  ID: `video-switcher`
- **投写比**（映像・制御）
  投写距離を投写画面の幅で割った比率。必要な画面幅と設置距離に適するレンズを考える際に使う。
  ID: `video-throw`
- **タイムコード**（映像・制御）
  時・分・秒・フレームなどの位置情報を表し、再生や各分野のキューを時間軸で同期させるために使う符号。
  ID: `video-timecode`
