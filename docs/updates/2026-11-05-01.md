# 現場用語を拡充

2026-11-05 · 193 件追加 / 14 件変更 / 0 件整理

劇場用語ハンドブック等の公開資料を確認し、わらう・ハケる・殺す・なぐり・三六・小屋付き・乗り打ち・中音/外音・客電・一ベル・カンペ・ドーラン・地方/立方など現場で慣用的に使われる用語193語を追加。ステマネ・ローホリ・客入れなど同義の呼び方は既存14項目の別名に追加。

## 追加

- **エアモニ**（音響）
  エアモニターの略。客席の音の状態を収音し、ホワイエや楽屋周りなどで舞台の進行を聞けるようにすること。またはその設備。
  ID: `audio-airmoni`
- **頭分け**（音響）
  一本のマイクの出力を分岐させ、複数の機器に送ること。録音や楽屋への送りなどに、同じ音を分けて使う。
  ID: `audio-atamawake`
- **デルマ**（音響）
  やわらかい芯を紙で巻いた筆記具の略称。書いたり消したりしやすいため、調整卓に回路名や機材名を書くのに使われる。
  ID: `audio-delma`
- **エレベーターマイク**（音響）
  遠隔操作で高さを変えられる電動昇降式のマイクスタンドを指す和製の呼び名。多くは舞台前の中央に設置され、調整室や袖から操作する。
  ID: `audio-elevmic`
- **擬音**（音響）
  本物とは別の物を使って表現した効果音のこと。小豆と籠で雨音を、お椀で馬の足音を表すなどの例がある。
  ID: `audio-gion`
- **8の字巻き**（音響）
  ケーブルを巻くとき、ひと巻きごとに巻く向きを交互に変えてまとめる方法。ねじれが溜まりにくく、次に伸ばすときに絡みにくい。
  ID: `audio-hachinoji`
- **ハウス送り**（音響）
  持ち込んだ音響卓の出力を劇場の音響設備に送り、調光室や楽屋などの運営系の設備でも聞けるようにすること。
  ID: `audio-housesend`
- **影アナ**（音響）
  観客から見えない場所で行う案内放送。会場の案内や禁止事項、上演に関する情報などを伝える。また、その担当者も指す。
  ID: `audio-kageana`
- **中音**（音響）
  演奏者がステージ上で聞く音のこと。ステージの内側に向けたモニタースピーカーなどから出す音を指す。
  ID: `audio-nakaoto`
- **生音**（音響）
  録音を使わず、効果音用の道具を実際に鳴らして作る音。また、台詞や歌を拡声や加工をせずにそのまま聞かせる音を指す。
  ID: `audio-namaoto`
- **ノンモン**（音響）
  ノン・モデュレーションの略。音がまったく入っていない無音の部分のことで、番組やCMの頭と終わりに置く。
  ID: `audio-nonmon`
- **音合わせ**（音響）
  楽器のチューニングや、歌手と演奏の調子を合わせること。また、本番前に実際の舞台で、進行に合わせて音量や音質、バランスを確認し調整することを指す。
  ID: `audio-otoawase`
- **音出し**（音響）
  演奏や稽古を始めること。「十二時音出し」は十二時から稽古や演奏を始めることを表す。音響システムから音を出して回路を確認することも指す。
  ID: `audio-otodashi`
- **外音**（音響）
  客席に向けたメインスピーカーから出し、観客に届ける音のこと。ステージ上の演奏者向けの音（中音）と対にして言う。
  ID: `audio-sotooto`
- **吊りマイク**（音響）
  ホールの天井などから吊り下げたマイク、またはその吊り下げの機構。主にクラシック音楽の録音に使う。
  ID: `audio-tsurimic`
- **ドーラン**（衣裳・メイク）
  舞台用の化粧材で、油脂に色素を加えて作るもの。
  ID: `costume-doran`
- **化粧前**（衣裳・メイク）
  楽屋に備えられた、鏡とセットになった化粧用の台。メイク道具を置いて使う。
  ID: `costume-keshomae`
- **拵え**（衣裳・メイク）
  日本舞踊などで、役の扮装全般を指す言葉。顔の拵えはメイクのことを言う。
  ID: `costume-koshirae`
- **素踊り**（衣裳・メイク）
  日本舞踊で、役柄に合わせた衣裳やかつらを着けずに踊ること。女性は紋服や無地の色物、男性は袴などを着る。
  ID: `costume-suodori`
- **床山**（衣裳・メイク）
  歌舞伎で、演者のかつらを結い上げたり、手入れや保管をしたりする係。またはその担当者。
  ID: `costume-tokoyama`
- **ベビー**（照明）
  ベビースポットの略で、小型のスポットライトを指す。劇場用語ハンドブックでは五百ワット以下の小型スポットとしている。
  ID: `lighting-baby`
- **べた明かり**（照明）
  真正面から当てる照明、または舞台全体を均等に明るくする照明のこと。
  ID: `lighting-betaakari`
- **直**（照明）
  照明の回路を、調光器を通さずに点灯すること。「六番をちょくって」のように動詞にしても使う。
  ID: `lighting-choku`
- **ちょんぱ**（照明）
  舞台と客席を暗くしておき、柝の「チョン」という音を合図に舞台を一斉に明るくする照明の演出。
  ID: `lighting-chonpa`
- **カットイン**（照明）
  照明や音を一瞬で入れること。キューシートなどでは CI と略して書く。照明ではスイッチインとも呼ぶ。
  ID: `lighting-cutin`
- **カットアウト**（照明）
  照明や音を一瞬で消すこと。キューシートなどでは CO と略して書く。
  ID: `lighting-cutout`
- **どんてら**（照明）
  緞帳を照らすための照明。またはそのために仕込まれた照明器具。
  ID: `lighting-donteru`
- **灯入れ**（照明）
  灯籠の明かりや遠くの家々の夜景などを表すため、道具の後ろから照明を当てて透かした部分を明るく見せること。またはそのために道具に仕込んだ照明器具。
  ID: `lighting-hiire`
- **星球**（照明）
  夜空の星を表すための小さな電球。低い電圧の電球を細いコードでつなぎ、吊り下げて星空のように見せる。
  ID: `lighting-hoshikyu`
- **介錯棒**（照明）
  吊り込んだ照明器具の当たりを、床から調整するときに使う長い棒。長さは二間ほどで、昔は竹竿を使っていた。
  ID: `lighting-kaishakubo`
- **こぼれる**（照明）
  照明で、スポットなどの光が舞台框や大臣柱など、当てたくない所に当たっていること。公演時間などが予定より延びることにも使う。
  ID: `lighting-koboreru`
- **客電**（照明）
  劇場やホールの客席の照明のこと。演出に合わせて明るさを変え、二十パーセントや五十パーセントなどと指示される。
  ID: `lighting-kyakuden`
- **目潰し**（照明）
  客席に向けて強い光を当て、観客の視線を一時的に舞台からそらす照明の技法。
  ID: `lighting-metsubushi`
- **盗む**（照明）
  キッカケの少し前から操作を始めること。照明や音響の操作で使う。
  ID: `lighting-nusumu`
- **先玉**（照明）
  エフェクトマシンなどの照明効果器の前面に取り付けるレンズの総称。オブジェクトレンズとも呼ぶ。
  ID: `lighting-sakidama`
- **サス残し**（照明）
  照明の技法の一つで、全体が消えた中で、サスペンションライトだけが特定の人物や道具を照らしている状態。
  ID: `lighting-susnokoshi`
- **合方**（楽器・音楽）
  歌舞伎の下座で三味線が演奏し、人物の出入りや幕の開閉などの雰囲気を作る曲。また、長唄などの声楽曲の中の長い間奏を指す。
  ID: `music-aikata`
- **合の手**（楽器・音楽）
  邦楽で、唄と唄の間をつなぐ楽器の旋律のこと。洋楽の間奏にあたる。
  ID: `music-ainote`
- **コンサートピッチ**（楽器・音楽）
  演奏の音の高さをそろえるために決めた基準。A（ラ）の音の周波数で表し、国際的には四百四十ヘルツとされる。
  ID: `music-concertpitch`
- **出囃子**（楽器・音楽）
  歌舞伎音楽の演奏形式で、囃子の演奏者が舞台の正面や上手・下手に出て演奏すること。寄席では、落語家などが出入りするときに陰で演奏する曲や、その演奏者を指す。
  ID: `music-debayashi`
- **義太夫**（楽器・音楽）
  竹本義太夫が江戸時代前期に始めた浄瑠璃の節。人形浄瑠璃（文楽）の語りや、歌舞伎の義太夫狂言の語りに用いられる。
  ID: `music-gidayu`
- **一番太鼓**（楽器・音楽）
  寄席などで、開場のときに鳴らす太鼓。「どんどん来い」と聞こえるように打つといわれる。
  ID: `music-ichibandaiko`
- **地方**（楽器・音楽）
  日本舞踊などで、唄や三味線、囃子などの伴奏を担当する人。踊り手を立方と呼ぶのに対して言う。
  ID: `music-jikata`
- **清元**（楽器・音楽）
  江戸時代後期に富本節から分かれて生まれた江戸浄瑠璃の一つ。歌舞伎舞踊の伴奏音楽として用いられる。
  ID: `music-kiyomoto`
- **メリヤス**（楽器・音楽）
  文楽で、舞台の効果を高めるため、人形の動きに合わせて三味線だけで演奏する音楽。
  ID: `music-meriyasu`
- **長唄**（楽器・音楽）
  唄と三味線に、小鼓や能管などの囃子を加えて演奏する三味線音楽。江戸の歌舞伎の伴奏音楽として発達した。
  ID: `music-nagauta`
- **2管編成**（楽器・音楽）
  オーケストラの規模を、木管楽器の各パートの人数で表す呼び方。各木管楽器が二人ずつの編成を二管編成と呼ぶ。
  ID: `music-nikan`
- **お調べ**（楽器・音楽）
  能楽で、開演前に鏡の間で笛や鼓、太鼓などが行う短い演奏。楽器の最終的な調整を兼ねる。
  ID: `music-oshirabe`
- **プルト**（楽器・音楽）
  ドイツ語で譜面台のこと。オーケストラの弦楽器では二人で一台の譜面台を見るため、奏者二人を一プルトと数える。
  ID: `music-pult`
- **四拍子**（楽器・音楽）
  能楽の囃子に使う、大鼓、小鼓、太鼓、能管の四つの楽器のこと。
  ID: `music-shibyoshi`
- **初見**（楽器・音楽）
  練習をせずに、初めて楽譜を見て演奏すること。台本を初めて見て読むことにも使う。
  ID: `music-shoken`
- **常磐津**（楽器・音楽）
  豊後節を改めて生まれた江戸浄瑠璃の一つで、常磐津文字太夫が始めた。歌舞伎舞踊の伴奏音楽として発達した。
  ID: `music-tokiwazu`
- **トラ**（楽器・音楽）
  エキストラの略で、オーケストラなどで正規の団員だけでは足りないパートを補う臨時の奏者。
  ID: `music-tora`
- **単相三線**（電源・通信）
  位相が百八十度異なる二本の電圧線に中性線を一本加え、単相の交流電力を送る方式。二本の電圧線の間は二百ボルト、中性線との間は百ボルトになる。
  ID: `network-1phase3w`
- **三相三線**（電源・通信）
  位相が百二十度ずつずれた交流電力を、三本の電線で送る方式。二百ボルトの動力用の電源として使われることが多い。
  ID: `network-3phase`
- **C型コネクター**（電源・通信）
  日本の舞台照明で使われるコネクターの形の呼び方の一つ。劇場用語ハンドブックは、照明用のコネクターとしてA型、C型、ミニC型、平行などを挙げている。
  ID: `network-cconnector`
- **二又**（電源・通信）
  オス一つに対してメスが二つに分かれている接続コード。タコや分岐とも呼ぶ。
  ID: `network-futamata`
- **先バラ**（電源・通信）
  コードやケーブルの先端の被覆を剥がし、芯線をばらばらに露出させた状態。
  ID: `network-sakibara`
- **あごあしまくら**（制作・運営）
  食費を「あご」、交通費を「あし」、宿泊費を「まくら」と呼ぶ俗称。「あごあし」でこれらの費用の総称を表す。
  ID: `production-agoashi`
- **煽る**（制作・運営）
  部署によって意味が変わる現場語。制作では時間が迫って急がせること、大道具では張物を少し後ろへ傾けて立てること、照明では複数の灯体を交互に明滅させたり、低い位置から上へ照らしたりすることを指す。
  ID: `production-aoru`
- **頭**（制作・運営）
  物事の初めや、始まりの部分のこと。「二幕の頭から返します」「音の頭から収録する」のように使う。
  ID: `production-atama`
- **ぶっつけ**（制作・運営）
  リハーサルや稽古をしないこと。簡単な打ち合わせだけで本番に臨むことを「ぶっつけ本番」と言う。
  ID: `production-bukkake`
- **台本**（制作・運営）
  上演台本の略。上演に必要な条件や指示などが書き込まれた脚本のこと。
  ID: `production-daihon`
- **ダメ出し**（制作・運営）
  演出家やスタッフが、仕込みから稽古、上演に至るまでの中で、直す必要のある所を指摘すること。囲碁の「駄目」から転じた言葉といわれる。
  ID: `production-dame`
- **段取り稽古**（制作・運営）
  大道具や小道具の確認、出ハケのタイミング、キッカケの調整などを中心に行う稽古。
  ID: `production-dandori`
- **芸中**（制作・運営）
  演劇やショーの正味の所要時間。舞台転換や休憩の時間は含めない。
  ID: `production-geinaka`
- **技打ち**（制作・運営）
  技術打ち合わせの略。収録や公演の前に、技術や美術、制作などのスタッフが集まって行う打ち合わせ。
  ID: `production-giuchi`
- **はねる**（制作・運営）
  その日の公演が終わること。歌舞伎劇場や寄席では、終演のことを「打ち出し」とも言う。
  ID: `production-hane`
- **本ベル**（制作・運営）
  公演や演奏会の開始を観客や出演者に告げるベル。二ベルや本鈴とも呼ぶ。
  ID: `production-honbell`
- **本読み**（制作・運営）
  出演者が台本を声に出して読み合わせる稽古。動きを付ける立ち稽古に入る前に、作品の内容や台詞の流れを確かめる。
  ID: `production-honyomi`
- **一ベル**（制作・運営）
  開演が近いことを観客や出演者に知らせるベルやブザー、チャイム。予鈴とも呼ぶ。
  ID: `production-ichibell`
- **入り**（制作・運営）
  公演の関係者が劇場や稽古場に到着すること。到着する時刻を「入り時間」と言い、出演者が楽屋に入ることを「楽屋入り」と言う。
  ID: `production-iri`
- **場内チェック**（制作・運営）
  開場前に、客席やロビー、ホワイエで不審物がないか、客席の椅子に不具合がないかなどを点検すること。
  ID: `production-jonai`
- **返し（稽古）**（制作・運営）
  稽古などで少し前に戻り、同じ部分をもう一度繰り返すこと。短い範囲を繰り返すことを「小返し」と言う。
  ID: `production-kaeshi`
- **買い公演**（制作・運営）
  制作する側が作品を作ってパッケージにしたものを、主催者が買い取って行う興行。
  ID: `production-kaikoen`
- **冠公演**（制作・運営）
  企業がスポンサーとなって行われる公演。公演名の頭に企業名を付けることからこう呼ぶ。
  ID: `production-kanmuri`
- **カンペ**（制作・運営）
  出演者への指示や台詞などを書いて示す用紙。本番中に、出演者から見える位置で掲げて伝える。
  ID: `production-kanpe`
- **顔寄せ**（制作・運営）
  稽古を始める前に、興行主や出演者、スタッフが一堂に集まる顔合わせ。歌舞伎では狂言作者が全員の名を読み上げ、最後に手締めをする儀式として行われる。
  ID: `production-kaoyose`
- **ケツ**（制作・運営）
  あらかじめ決まっている終わりの時刻。カットや素材の最後の部分を指すこともある。
  ID: `production-ketsu`
- **キッカケ合わせ**（制作・運営）
  キッカケのある所だけを取り出し、音楽や出演者の動きと、照明・音響の変化を合わせる稽古。
  ID: `production-kikkakeawase`
- **こけら落とし**（制作・運営）
  新築や改築をした劇場で、開場を披露する最初の興行。竣工や開館を記念する公演を指す。
  ID: `production-kokera`
- **小屋付き**（制作・運営）
  劇場やホールに常駐している舞台技術のスタッフ。舞台、照明、音響などの専門分野を担当する。
  ID: `production-koyatsuki`
- **食う**（制作・運営）
  相手の台詞を最後まで言わせずに自分の台詞を言うこと。また、演技力で相手役を圧倒することも指す。
  ID: `production-kuu`
- **客止め**（制作・運営）
  開演後、演出や演奏の妨げにならないよう、遅れて来た観客の客席への出入りを止めること。
  ID: `production-kyakudome`
- **曲間入場**（制作・運営）
  途中入場の一種で、遅れて来た観客を、演奏が終わり次の曲が始まるまでの間に客席へ案内すること。
  ID: `production-kyokukan`
- **ロビー開場**（制作・運営）
  開場の時刻になっても舞台の準備やリハーサルの遅れで客席に案内できないとき、観客にロビーまで入ってもらうこと。
  ID: `production-lobbyopen`
- **幕間**（制作・運営）
  幕が閉まってから次の幕が開くまでの間。転じて、公演の休憩時間を指す。
  ID: `production-makuai`
- **もぎり**（制作・運営）
  劇場の入口で入場券を確かめ、半券をちぎって観客を入場させること。またはその係。
  ID: `production-mogiri`
- **乗り日**（制作・運営）
  旅公演で、次の公演地へ移動するための日。
  ID: `production-noribi`
- **乗り打ち**（制作・運営）

  ID: `stage-warudon`
- **山台**（舞台・劇場）
  歌舞伎舞踊などで、長唄や常磐津、清元などの演奏者が乗る台。平台と足で組み、毛氈を掛けて使う。
  ID: `stage-yamadai`
- **屋台**（舞台・劇場）
  舞台上に組み立てた、家屋の形をした舞台装置。歌舞伎などでは座敷や町家を表すのに使う。
  ID: `stage-yatai`
- **雪籠**（舞台・劇場）
  舞台に雪を降らせるための目の粗い籠。バトンに吊って中に紙片を入れ、揺らして降らせる。
  ID: `stage-yukikago`
- **カメリハ**（映像・制御）
  カメラリハーサルの略。本番に近い形で、出演者の動きやカメラワークなどを確認するリハーサル。
  ID: `video-camerehe`
- **完パケ**（映像・制御）
  テロップ入れや音の仕上げの作業を終え、そのまま放送に出せる状態になった映像のこと。
  ID: `video-kanpake`
- **回す**（映像・制御）
  撮影や収録を始めること。またはカメラが撮影している状態を指す。
  ID: `video-mawasu`
- **なめる**（映像・制御）
  手前にある物や人物を画面に入れながら、その向こうの被写体を撮る撮り方。足元から顔へ向かって撮っていく撮り方を指すこともある。
  ID: `video-nameru`
- **抜け**（映像・制御）
  カメラが向いている方向の背景のこと。被写体の後ろに何が写るかを指して言う。
  ID: `video-nuke`
- **パカチェック**（映像・制御）
  画面が瞬間的に明るくなったり暗くなったりする「パカつき」が、視聴者の光過敏性発作を引き起こさないかを確認する工程。
  ID: `video-pakacheck`
- **テロップ**（映像・制御）
  映像の画面に重ねて表示する文字情報のこと。スーパーとも呼ぶ。
  ID: `video-telop`
- **撮って出し**（映像・制御）
  撮影したばかりの映像を、編集せずにそのまま放送などに出すこと。時間がほとんどないことの例えにも使う。
  ID: `video-torittedashi`
- **寄り・引き**（映像・制御）
  寄りはカメラを被写体に近づけたりズームしたりして大きく写すこと。引きは被写体から離れ、余裕を持たせた広い画面にすること。
  ID: `video-yorihiki`

## 変更

- **かぶり**（音響） — 変更項目: aliases / sources
  狙った音源以外の楽器音、周囲の音、スピーカー音などがマイクへ入ること。分離の程度やミックスの質感に影響する。
  ID: `audio-bleed`
- **モニタースピーカー**（音響） — 変更項目: aliases / sources
  舞台上の出演者へ必要な音を返すスピーカー。床置きのくさび形が代表的だが、配置や形状にはさまざまな種類がある。
  ID: `audio-monitor`
- **早替え**（衣裳・メイク） — 変更項目: aliases / sources
  公演の進行中に、限られた時間で衣裳や外見を替えること。舞台上で見せる場合と袖で行う場合がある。
  ID: `costume-quickchange`
- **不滅電源**（照明） — 変更項目: aliases / sources
  照明卓の調光に連動して電源が絞られない供給系統を指す現場語。常時給電の範囲や主電源の扱いは、施設の設備によって異なる。
  ID: `lighting-constantpower`
- **フォーカス**（照明） — 変更項目: aliases / sources
  灯体の照射位置、大きさ、輪郭などを目的に合わせる作業。光学系の像のピントだけを指す場合もある。
  ID: `lighting-focus`
- **フォロースポット**（照明） — 変更項目: aliases / sources
  動く出演者などを追尾して照らすスポット。人が直接操作する方式のほか遠隔操作する方式もある。
  ID: `lighting-followspot`
- **ロアーホリゾント**（照明） — 変更項目: aliases / sources
  ホリゾント幕を床付近から照らす照明。背景下部からの色や明るさを作る用途に使われる。
  ID: `lighting-lowercyc`
- **PARライト**（照明） — 変更項目: aliases / sources
  伝統的には反射鏡・光源・レンズを一体化したPARランプを用いる器具。LED型もPARの名称で流通する。
  ID: `lighting-par`
- **開場**（制作・運営） — 変更項目: aliases / sources
  観客を客席や会場へ入れ始めること。作品の上演が始まる開演とは別の時点で、ロビー開場だけを先に行う場合もある。
  ID: `production-houseopen`
- **舞台監督**（制作・運営） — 変更項目: aliases / sources
  稽古と本番の進行を支え、出演者と技術各部門をつなぐ担当。具体的な職務や権限は公演・国・組織により異なる。
  ID: `production-sm`
- **二次落下防止**（安全・仕込み） — 変更項目: aliases / sources
  主な取付部が機能しなくなった場合に備え、機材などの落下を抑えるために設ける独立した保持。
  ID: `safety-secondary`
- **ホイスト**（舞台・劇場） — 変更項目: aliases / sources
  荷を持ち上げたり下げたりするための装置。舞台では幕、道具、照明バー等の昇降に使う。
  ID: `stage-hoist`
- **傾斜舞台**（舞台・劇場） — 変更項目: aliases / sources
  舞台床が傾斜している舞台。古典的な劇場では舞台奥が高い構成があり、作品の美術として傾斜床を設ける場合もある。
  ID: `stage-rake`
- **床**（舞台・劇場） — 変更項目: aliases / sources
  歌舞伎で、上手側に設ける竹本の語りと三味線の演奏場所。御簾を上げて姿を見せる演奏と、隠した演奏がある。
  ID: `stage-yuka`
