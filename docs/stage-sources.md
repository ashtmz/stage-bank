# 舞台用語の参照資料

確認日: 2026-11-03

130 項目。本文は用語の事実を日本語で独自に要約したもの。名称が近くても地域や設備で一対一に対応しない語は注記を付ける。

## 方向の基準

- 上手 = 客席から右 = 演者から左 = Stage left = 仏 côté cour。
- 下手 = 客席から左 = 演者から右 = Stage right = 仏 côté jardin。
- 英国の Prompt side は通常 Stage left。卓位置が例外の劇場もあるため現場図面の凡例を優先。
- フランス語 cour/jardin は Comédie-Française の公式 FAQ と Opéra national de Paris の語彙解説を照合。

## 編集方針

- 日本固有の花道・能舞台の構造などにはローマ字と機能説明を付け、ランウェイなどへ安易に置換しない。
- 欧州欄は仏・独・伊のどの語かを明記する。欧州共通の規格や名称とは扱わない。
- 機構や防火設備は用語説明に留め、操作方法、強度、許容値、法的適合を推定しない。
- 字幕や別名だけを独立項目として重複登録せず、aliases に収録する。
- 紗幕の Scrim/Gauze、平台の Platform/Rostrum、客席の Stalls/Orchestra などは使用域・範囲の違いを注記。
